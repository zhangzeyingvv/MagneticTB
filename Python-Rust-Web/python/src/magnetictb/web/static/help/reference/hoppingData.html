hoppingData

把当前模型已求解键层和参数规则转换为数值实空间 hopping 数据。

Convert solved current-model shells and parameter rules into numeric real-space hopping data.

01

hoppingData(selection, rules, *, Hermitian=True, KernelMethod="Iterative", ValidationLevel="Basic") → dict

参数Parameter默认值Default作用Purpose
selection—正整数 n 选择 1..n 层；正整数序列只选择列出的层并保持首次出现顺序。A positive integer n selects shells 1 through n; a positive-integer sequence selects only those shells in first-occurrence order.
rules—参数名到数值的映射，或有序 (name, value) 序列。Mapping from parameter names to values, or an ordered sequence of (name, value) pairs.
HermitianTrue是否按 Hermitian 模式求解所选键层。Whether to solve selected shells in Hermitian mode.
KernelMethod"Iterative"零空间策略："Iterative"、"Stacked" 或 "Cyclotomic"；失败时不自动换方法。Null-space strategy: "Iterative", "Stacked", or "Cyclotomic"; failure never switches methods automatically.
ValidationLevel"Basic"验证等级："None"、"Basic" 或 "Full"。Validation level: "None", "Basic", or "Full".

selection=2 表示 1..2 层；selection=[2] 只选择第二层。本页示例使用后者。

selection=2 means shells 1 through 2; selection=[2] selects shell 2 only. This page demonstrates the latter form.

简单立方最近邻 hoppingSimple-cubic nearest-neighbour hoppings

02
# 生成并检查实空间 hopping 数据结构# Generate and inspect the real-space hopping data structure
from magnetictb import gray, hoppingData, init, msgop, symbol, symham

a = symbol("a")
operations = msgop(gray[221])
init(
    lattice=((a, 0, 0), (0, a, 0), (0, 0, a)),
    lattpar=((a, 1),),
    wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
    symminformation=operations,
    basis_functions=(("s",),),
    initial_bond_shells=2,
    generate_symmetry_group=False,
)
symham(2)
nearest_hoppings = hoppingData([2], {"t1": 1})
print(nearest_hoppings["Translations"])
print(nearest_hoppings["HoppingMatrices"])
