hop

把已求出的键层或有限指数形式的 Bloch Hamiltonian 写成 Wannier90 hr.dat 文本。

Write prepared shells or a finite-exponential Bloch Hamiltonian as Wannier90 hr.dat text.

01

hop(selection, rules, *, Hermitian=True, KernelMethod="Iterative", ValidationLevel="Basic", hrExport=None, RealDigits=12, wcc="Automatic", TranslationTolerance=1e-9) → str

参数Parameter默认值Default作用Purpose
selection必填required一个 Hamiltonian、一个 shell、shell 序列或普通符号矩阵；整数 n 表示第 1 至第 n 层。A Hamiltonian, one shell, a shell sequence, or an ordinary symbolic matrix; integer n means shells 1 through n.
rules必填required覆盖所选 Hamiltonian 参数的数值映射。A numerical mapping covering the selected Hamiltonian parameters.
HermitianTrue按键层导出时选择相同的厄米求解设置。Select the matching Hermitian solve setting when exporting shells.
KernelMethod"Iterative""Iterative" / "Stacked" / "Cyclotomic"。"Iterative" / "Stacked" / "Cyclotomic".
ValidationLevel"Basic""None" / "Basic" / "Full"。"None" / "Basic" / "Full".
hrExportNone打印并返回文本，或写入指定文件/目录。Print and return text, or write the specified file/directory.
RealDigits12输出小数位数，至少为 6。Number of output decimal digits; at least 6.
wcc"Automatic"从当前模型取得中心，或显式提供每个轨道的分数坐标。Use current-model centres or supply one fractional centre per orbital.
TranslationTolerance1e-9从用户矩阵的指数相位提取整数平移时使用的容差。Tolerance used to recover integer translations from exponent phases in a user matrix.

selection 可为一个 Hamiltonian 对象、一个 shell、shell 序列，或普通符号矩阵。整数 n 表示第 1 至第 n 层；序列只导出列出的层。rules 是参数名到数值的映射。

selection may be a Hamiltonian, one shell, a shell sequence, or an ordinary symbolic matrix. Integer n means shells one through n, while a sequence exports only its listed shells. rules maps parameter names to values.

H_{mn}(\mathbf R)=\frac{1}{N_k}\sum_{\mathbf k}H_{mn}(\mathbf k)e^{-i\mathbf k\cdot\mathbf R}.
hrExport=None 会返回并打印完整文本；给文件路径则写该文件，给已存在目录则写 wannier90_hr.dat。下例使用临时目录，实际程序会返回完整绝对路径。hrExport=None returns and prints the complete text. A file path writes that file; an existing directory writes wannier90_hr.dat. The examples use a temporary directory; the actual program returns its full path.

石墨烯 HR 文件Graphene HR file

Input 1 · 初始化并组合三个键层Initialize and combine three shells

# 初始化并组合三个键层# Initialize and combine three shells
from fractions import Fraction
from pathlib import Path
from tempfile import TemporaryDirectory

from magnetictb import (
    gray, hamiltonian_object, hop, init, msgop,
    readHR, sqrt, symbol, symham,
)

a, c = symbol("a"), symbol("c")
third = Fraction(1, 3)
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 3)),
    wyckoffposition=(((third, 2 * third, 0), (0, 0, 0)),),
    symminformation=msgop(gray[191]),
    basisFunctions=(("pz",),),
    InitialBondShells=3,
    GenerateSymmetryGroup=False,
)
ham = hamiltonian_object(1) + hamiltonian_object(2) + hamiltonian_object(3)

Input 2 · 由完整 Hamiltonian 写出并显示前 12 行Write the complete Hamiltonian and show its first 12 lines

# 由完整 Hamiltonian 写出并显示前 12 行# Write the complete Hamiltonian and show its first 12 lines
with TemporaryDirectory() as directory:
    hr_file = Path(directory) / "graphene_hr.dat"
    written = hop(
        ham,
        {"e1": 0.05, "r1": 0.02, "t1": 0.5},
        hrExport=hr_file,
        wcc="Automatic",
    )
    print("\n".join(Path(written).read_text().splitlines()[:12]))
