readHR

严格读取完整的 Wannier90 hr.dat，验证文件头、简并度、平移、轨道编号和复矩阵元。

Strictly parse a complete Wannier90 hr.dat, validating its header, degeneracies, translations, orbital indices, and complex matrix elements.

01

readHR(file, *, prec=1e-10, ncell="All") → dict

参数Parameter默认值Default作用Purpose
file—Wannier90 hr.dat 文件路径。Path to a Wannier90 hr.dat file.
prec1e-10把绝对值小于该非负有限数的矩阵元实部或虚部截为 0。Finite nonnegative cutoff that sets a matrix element’s real or imaginary part to zero when its absolute value is smaller.
ncell"All""All" 保留全部平移；非负整数 n 只保留三个分量都满足 |Rᵢ|≤n 的平移块。"All" keeps every translation; a nonnegative integer n keeps blocks whose three translation components all satisfy |Rᵢ|≤n.

返回值包括 Translations、HoppingMatrices、NumWannier、NumTranslations、Degeneracies、HermitianResidual 等字段。把该字典交给 buildBlochHamiltonian 可恢复数值 Bloch 矩阵。

The result contains Translations, HoppingMatrices, NumWannier, NumTranslations, Degeneracies, HermitianResidual, and related fields. Pass it to buildBlochHamiltonian to reconstruct a numerical Bloch matrix.

H(\mathbf k)=\sum_{\mathbf R}H(\mathbf R)e^{i\mathbf k\cdot\mathbf R}.

Basic Examples

写出、读回并恢复 H(k)Write, read, and rebuild H(k)

02

Input 1

沿用 hop 页的石墨烯初始化：

Continue from the Graphene initialization on the hop page:

# 读取 hopping 文件并检查重建结果# Read a hopping file and inspect the reconstructed result
from magnetictb import buildBlochHamiltonian, hop, readHR

with TemporaryDirectory() as directory:
    hr_file = Path(directory) / "graphene_hr.dat"
    hop(
        (1, 2, 3),
        {"e1": 0.05, "r1": 0.02, "t1": 0.5},
        hrExport=hr_file,
        wcc="Automatic",
    )
    hr_data = readHR(hr_file)
    gamma = buildBlochHamiltonian(hr_data, (0, 0, 0))
    print(gamma)
[[(0.16999999999999998+0j), (1.5+0j)],
 [(1.5+0j), (0.16999999999999998+0j)]]

HR 是有限小数文本，因此读回值是普通浮点复数；0.16999999999999998 就是二进制浮点表示的 0.17。

HR is decimal text, so parsed values are ordinary floating complex numbers; 0.16999999999999998 is the binary floating representation of 0.17.

Input 2 · prec=1e-12

先写出 e1=1.0、r1=t1=1e-13，再把小量截为零：

Write e1=1.0 and r1=t1=1e-13, then chop tiny entries:

# 读取 hopping 文件并检查重建结果# Read a hopping file and inspect the reconstructed result
hop(
    (1, 2, 3),
    {"e1": 1.0, "r1": 1e-13, "t1": 1e-13},
    hrExport=tiny_hr_file,
    wcc="Automatic",
)
tiny = readHR(tiny_hr_file, prec=1e-12)
first_nonzero_translation_matrix = next(
    matrix
    for translation, matrix in zip(
        tiny["Translations"], tiny["HoppingMatrices"]
    )
    if translation != [0, 0, 0]
)
print(first_nonzero_translation_matrix)
[[0j, 0j],
 [0j, 0j]]

完整文件先经过解析和验证，然后才按 max(abs(Ri)) ≤ ncell 截取。

The complete file is parsed and validated before translations are truncated by max(abs(Ri)) ≤ ncell.
