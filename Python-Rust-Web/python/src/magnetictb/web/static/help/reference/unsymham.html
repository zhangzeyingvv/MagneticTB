unsymham(shell)

返回当前会话指定键层在施加空间群约束之前的完整普通二维符号矩阵。

Return the complete ordinary two-dimensional symbolic matrix of one current-session shell before space-group constraints are imposed.

01

unsymham(shell) → list[list[HamiltonianExpression]]

参数Parameter默认值Default作用Purpose
shell必填required当前会话中已经准备的 1-based 物理键层；一次只返回这一层。A prepared 1-based physical shell in the current session; one call returns that shell only.

每条有向键具有独立实部/虚部参数；symham 再由群作用把它们约束到对称允许的参数空间。

Every directed bond has independent real/imaginary parameters; symham then constrains them to the symmetry-allowed parameter space.

Basic Example · input 1

简单立方 s 轨道第二键层Simple-cubic s orbital, shell 2

02
# 生成并检查未施加对称约束的 Hamiltonian# Generate and inspect a Hamiltonian without symmetry constraints
from magnetictb import gray, init, msgop, symbol, unsymham

a = symbol("a")
operations = msgop(gray[221])
init(
    lattice=((a, 0, 0), (0, a, 0), (0, 0, a)),
    lattpar=((a, 1),),
    wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
    symminformation=operations,
    basis_functions=(("s",),),
    initial_bond_shells=2,
    generate_symmetry_group=False,
)
matrix = unsymham(2)
print([[str(entry) for entry in row] for row in matrix])

Properties & Relations · input 2

施加对称性后的结果After imposing symmetry

# 生成并检查未施加对称约束的 Hamiltonian# Generate and inspect a Hamiltonian without symmetry constraints
from magnetictb import symham

unconstrained = unsymham(2)
constrained = symham(2)
print([[str(entry) for entry in row] for row in unconstrained])
print([[str(entry) for entry in row] for row in constrained])
params: ['tr111', 'ti111', 'tr211', 'ti211', 'tr311', 'ti311',
         'tr411', 'ti411', 'tr511', 'ti511', 'tr611', 'ti611']
params: ['t1']
[['tr111*exp(I*(-kx)) + I*ti111*exp(I*(-kx)) + '
  'tr211*exp(I*(-ky)) + I*ti211*exp(I*(-ky)) + '
  'tr311*exp(I*(-kz)) + I*ti311*exp(I*(-kz)) + '
  'tr411*exp(I*(kz)) + I*ti411*exp(I*(kz)) + '
  'tr511*exp(I*(ky)) + I*ti511*exp(I*(ky)) + '
  'tr611*exp(I*(kx)) + I*ti611*exp(I*(kx))']]
[['t1*exp(I*(-kx)) + t1*exp(I*(-ky)) + t1*exp(I*(-kz)) + '
  't1*exp(I*(kz)) + t1*exp(I*(ky)) + t1*exp(I*(kx))']]

两个矩阵都完整列出。六个独立复参数被对称性约束为一个实参数 t1。

Both matrices are printed in full. Symmetry reduces six independent complex parameters to one real parameter, t1.
