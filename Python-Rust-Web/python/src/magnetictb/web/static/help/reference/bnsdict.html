bnsdictReference Page

Reference Page

bnsdict[(n, m)]

按完整 BNS 编号 n.m 返回 stable MSGOP 序号。

Return a stable MSGOP index from the complete BNS number n.m.

01

bnsdict[(n, m)] → int

参数Parameter默认值Default作用Purpose
(n, m)必填required完整 BNS 编号的二整数元组。A two-integer tuple containing the complete BNS number.

bnsdict 是包含 1651 个 BNS 编号对的只读 Mapping。typeI、gray、typeIII、typeIV 是同一组 stable 序号的分类视图。

bnsdict is a read-only Mapping containing all 1,651 BNS number pairs. typeI, gray, typeIII, and typeIV are classified views of the same stable indices.
