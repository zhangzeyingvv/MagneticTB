grayrod[n]

按杆群编号 1–75 返回灰磁杆群的三整数 stable 数据库标识；用 mrgop 读取完整操作。

Return the three-integer stable database selector of gray magnetic rod group 1–75; use mrgop for its complete operations.

01

grayrod[n] → tuple[int, int, int]

参数Parameter默认值Default作用Purpose
n必填required1–75 的杆群编号。A rod-group number from 1 through 75.

grayrod[25] 本身是 (25, 2, 129)。

grayrod[25] itself is (25, 2, 129).
