orbitalTable

返回当前模型的完整 Hamiltonian 基顺序。

Return the complete Hamiltonian basis order of the current model.

01

orbitalTable(*, model=None) → TableReport

参数Parameter默认值Default作用Purpose
modelNoneNone 读取由 init 或 initfromrep 安装的当前会话；也可传入独立 PreparedModel。None reads the session installed by init or initfromrep; a detached PreparedModel may also be supplied.

结果不可变，可迭代，并可用 to_dict() 转成普通结构。

The immutable result is iterable and supports to_dict().

# 初始化模型并检查 Hamiltonian 轨道顺序# Initialize the model and inspect the Hamiltonian orbital order
from fractions import Fraction
from magnetictb import gray, init, msgop, orbitalTable, symbol

a = symbol("a")
init(
    lattice=((a, 0, 0), (0, a, 0), (0, 0, a)),
    lattpar=(("a", 1),),
    wyckoffposition=(
        ((0, 0, 0), (0, 0, 0)),
        ((Fraction(1, 2), Fraction(1, 2), Fraction(1, 2)), (0, 0, 0)),
    ),
    symminformation=msgop(gray[221]),
    basisFunctions=(("s",), ("s",)),
    InitialBondShells=2,
    GenerateSymmetryGroup=False,
)
report = orbitalTable()
rows = report.to_dict()["rows"]
print(report.title)
for row in rows:
    print(row["HamiltonianIndex"], row["SiteIndex"],
          row["WyckoffOrbitIndex"], row["FractionalPosition"],
          row["BasisFunctionInput"], row["BasisState"])

# 建立双群 Induced 模型并打印轨道表与 onsite Hamiltonian# Build a double-group Induced model and print its orbital table and onsite Hamiltonian
from contextlib import redirect_stdout
from fractions import Fraction
from io import StringIO

from magnetictb import init, orbitalTable, symham

identity = ((1, 0, 0), (0, 1, 0), (0, 0, 1))
c2z = ((-1, 0, 0), (0, -1, 0), (0, 0, 1))
tau = (Fraction(1, 2), 0, 0)

# 四个操作按 E、半平移、C2z、C2z+半平移的顺序给出# Supply E, half translation, C2z, and C2z plus half translation in order
with redirect_stdout(StringIO()):
    init(
        lattice=identity,
        wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
        symminformation=(
            ("E", identity, (0, 0, 0), "F"),
            ("tau", identity, tau, "F"),
            ("C2z", c2z, (0, 0, 0), "F"),
            ("C2z tau", c2z, tau, "F"),
        ),
        basisFunctions=(("sup", "sdn"),),
        InitialBondShells=1,
        RepresentationMode="Induced",
    )

for row in orbitalTable().to_dict()["rows"]:
    print(
        row["SiteIndex"], row["BasisFunctionInput"], row["BasisState"],
        row["SpatialOrbital"], row["SpinState"], row["SpinStructure"],
        row["ReferenceEquivalentAtomIndex"],
        row["TransportOperationIndex"], row["TransportOperationLabel"],
    )

with redirect_stdout(StringIO()):
    onsite = symham(1)
print([[str(entry) for entry in row] for row in onsite])

sup 与 sdn 保持为两个不同旋量基态；第二个格点由操作 2（tau）从参考格点搬运得到。symham(1) 的行列顺序与这四行完全相同。

sup and sdn remain distinct spinor states. Operation 2 (tau) transports them from the reference site to site 2. The row and column order of symham(1) is exactly the four-row order above.

Properties & Relations

如何读这张表How to read the table

04

显示字段 HamiltonianIndex、SiteIndex、WyckoffOrbitIndex、LocalOrbitalIndex、ReferenceEquivalentAtomIndex 与 TransportOperationIndex 都是 1-based。Python 容器本身的下标仍是 0-based。

Display fields HamiltonianIndex, SiteIndex, WyckoffOrbitIndex, LocalOrbitalIndex, ReferenceEquivalentAtomIndex, and TransportOperationIndex are 1-based. Python container subscripts remain 0-based.

BasisFunctionInput 保留用户给出的 catalog 或抽象表示标签；BasisState 是 Rust 解析或搬运后的实际 Hamiltonian 基态。Induced 行同时给出参考等价原子与搬运操作；DirectProduct 行的这些字段为 None。

BasisFunctionInput preserves the user-supplied catalogue or abstract representation label; BasisState is the actual Hamiltonian basis state resolved or transported by Rust. Induced rows also report the reference equivalent atom and transport operation; these fields are None for DirectProduct rows.
