grayReference Page

Reference Page

gray[n]

返回与普通空间群编号 n 对应的灰磁空间群 stable MSGOP 序号。

Return the stable MSGOP index of the gray magnetic space group associated with ordinary space-group number n.

01

gray[n] → int

参数Parameter默认值Default作用Purpose
n必填required1–230 的普通空间群编号。An ordinary space-group number from 1 through 230.

gray 是只读 Mapping，键为 1–230。返回值是数据库序号，不是操作列表；把它交给 msgop 或 showMSGWyckoff。

gray is a read-only Mapping with keys 1–230. Its value is a database index, not an operation list; pass it to msgop or showMSGWyckoff.
