init

根据晶格、Wyckoff 位置、对称性和局域轨道建立当前紧束缚模型。

Install the current tight-binding model from a lattice, Wyckoff seeds, symmetry operations, and local orbitals.

01

init(*, lattice=None, lattpar=None, wyckoffposition=None, symminformation=None, basis_functions=("s",), debug_q=False, initial_bond_shells=10, generate_symmetry_group=False, representation_mode="DirectProduct", exact_field=None, **stable_options) → None

参数Parameter默认值Default作用Purpose
latticeNone三条正格矢按行存储，可以包含精确符号表达式。省略时使用内置的六方符号晶格。Three row lattice vectors, optionally containing exact symbolic expressions. Omitting it selects the built-in symbolic hexagonal lattice.
lattparNone为晶格符号提供实数值，用于数值键搜索；省略时使用 a=1, c=3。Real values for lattice symbols used by the numerical bond search; omission uses a=1, c=3.
wyckoffpositionNone保持顺序的 (分数坐标种子, 磁矩) 序列，也可使用 Wyckoff。省略时使用内置种子。An ordered sequence of (fractional seed, moment) pairs, or Wyckoff data. Omission uses the built-in seed.
symminformationNonemsgop(...) 返回的完整有序操作表、MSG，或有序自旋空间群操作；省略时只有恒等操作。A complete ordered table from msgop(...), an MSG, or ordered spin-space operations; omission uses only the identity operation.
basis_functions
basisFunctions		("s",)每个 Wyckoff 轨道一组内置 catalog 标签或一个 ExplicitPolynomialBasis；外层顺序必须与 Wyckoff 轨道一致。One built-in catalogue sequence or one ExplicitPolynomialBasis per Wyckoff orbit; the outer order must match the Wyckoff orbits.
debug_q
debugQ		False布尔诊断标志；普通建模保持 False。Boolean diagnostic flag; keep it False for ordinary modeling.
initial_bond_shells
InitialBondShells		10初始化时准备的完整键层数，必须是正整数；第 1 层为 onsite，第 2 层为第一个非零距离层。Number of complete bond shells prepared during initialization; it must be a positive integer. Shell 1 is onsite and shell 2 is the first nonzero-distance shell.
generate_symmetry_group
GenerateSymmetryGroup		FalseFalse 把显式操作序列视为完整群；True 把它视为生成元并在 Rust 中闭合有限群。False treats an explicit operation sequence as the complete group; True treats it as generators and closes the finite group in Rust.
representation_mode
RepresentationMode		"DirectProduct""DirectProduct" 在每个等价点保留完整输入局域基；"Induced" 从参考点稳定子群表示搬运到其他等价点。"DirectProduct" keeps the complete input local basis at every equivalent site; "Induced" transports a reference-site stabilizer representation to the other sites.
exact_fieldNone高级选项：指定 ExactField。省略时使用 ExactField.crystallographic()。Advanced option selecting an ExactField. Omission uses ExactField.crystallographic().

init 成功后把模型安装到当前 context-local 会话；随后调用 orbitalTable()、showbonds(shell) 和 symham(shell)。每次调用先清空旧会话，失败时不会沿用上一个模型。

After success, init installs a context-local model used by orbitalTable(), showbonds(shell), and symham(shell). Every call clears the old session first, so a failed initialization never reuses it.

表中并列的 snake_case 与稳定风格名称是同一选项的两种拼写；一次调用请选择其中一种。lattice、lattpar、wyckoffposition 和 symminformation 两种风格名称相同。Paired snake-case and stable-style names are two spellings of the same option; use one spelling per call. lattice, lattpar, wyckoffposition, and symminformation already have the same spelling in both styles.

输入 1 · 完整初始化Input 1 · complete initialization

# 导入精确数、群数据和模型检查函数# Import exact numbers, group data, and model-inspection functions
from fractions import Fraction

from magnetictb import gray, init, msgop, orbitalTable, bondTable
from magnetictb import showSymmetryRepresentations, sqrt, symbol

a = symbol("a")
c = symbol("c")
one_third = Fraction(1, 3)

# 操作顺序决定后续表示矩阵的顺序# Operation order determines the order of later representation matrices
graphene_operations = msgop(gray[191])
# init 安装当前会话；返回值本身是 None# init installs the current session; its return value is None
result = init(
    lattice=(
        (a, 0, 0),
        (-a / 2, sqrt(3) * a / 2, 0),
        (0, 0, c),
    ),
    lattpar=(("a", 1), ("c", 3)),
    wyckoffposition=(((one_third, 2 * one_third, 0), (0, 0, 0)),),
    symminformation=graphene_operations,
    basisFunctions=(("pz",),),
)
print(result)

只输入参考点的 px；Rust 按稳定陪集顺序用操作 1、5、9 将它搬运为三个实际状态 x,z,y，所以维数为 3。BasisFunctionInput 始终保留输入标签 px；BasisState、参考等价原子和搬运操作字段给出实际 Hamiltonian 基的来源。操作标签中的双引号是 Data 标签本身的一部分。

Kagome：含自旋的双群诱导表示Kagome: a spinful double-valued induced representation

磁空间群 BNS 191.239（P6′/m′mm′）把参考点上的旋量 (1, −1)/√2 搬运到三个格点。每个格点保留一个选定的局域态，所得 Hamiltonian 有三条能带。

Magnetic space group BNS 191.239 (P6′/m′mm′) transports the reference spinor (1, −1)/√2 to three sites. One selected local state per site gives three bands.

# 只在参考格点输入一个二分量旋量# Supply one two-component spinor at the reference site
from fractions import Fraction
from magnetictb import ExplicitPolynomialBasis, init, msgop
from magnetictb import orbitalTable, root_of_unity, sqrt, symbol, typeIII

a, c = symbol("a"), symbol("c")
# q = 1/sqrt(2)，用精确单位根表示常数系数# q = 1/sqrt(2), encoded as an exact root-of-unity coefficient
q = (root_of_unity(8, 1) + root_of_unity(8, -1)) / 2
local_spinor = ExplicitPolynomialBasis(((q, -q),))

init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 8)),
    wyckoffposition=(((Fraction(1, 2), 0, 0), (1, 0, 0)),),
    symminformation=msgop(typeIII[(191, 239)]),
    basisFunctions=local_spinor,
    RepresentationMode="Induced",
    InitialBondShells=3,
)
# 按 Hamiltonian 的行列顺序查看生成的三个格点# Inspect the three generated sites in Hamiltonian row/column order
for row in orbitalTable().to_dict()["rows"]:
    print(row["HamiltonianIndex"], row["FractionalPosition"])
