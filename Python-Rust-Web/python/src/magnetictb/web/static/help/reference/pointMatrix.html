pointMatrix

给出各点操作在有序局域轨道或旋量基底上的精确矩阵。每个操作写成 [label, R, t, flag]；返回顺序与操作顺序一致。

Return exact matrices of point operations on an ordered local-orbital or spinor basis. Every operation is [label, R, t, flag], and result order matches operation order.

01

pointMatrix(symmetry_information, orbit_basis, evaluated_lattice, *, exact_field=None) → list[list[list]]

参数Parameter默认值Default作用Purpose
symmetry_information—非空有序操作序列；接受 SymmetryOperation 或 [label, R, t, "F"/"T"]。Nonempty ordered operations, as SymmetryOperation objects or [label, R, t, "F"/"T"] records.
orbit_basis—有序 catalog 基标签，或一个 ExplicitPolynomialBasis。Ordered catalogue basis labels or one ExplicitPolynomialBasis.
evaluated_lattice—已经代入数值或精确常数的 3×3 行晶格。Evaluated 3-by-3 row lattice using numerical or exact constants.
exact_fieldNone高级选项：指定 ExactField；省略时使用晶体学精确数域。Advanced ExactField override; omission uses the crystallographic exact field.

第 j 列是变换后状态在原有序基底中的展开系数。平移保留在群元中，但局域轨道矩阵只由点操作决定。数学由 Rust 精确内核计算。

Column j contains the expansion coefficients of the transformed state in the original ordered basis. Translation stays in the group record, while the local-orbital matrix depends on the point operation. Rust performs the exact mathematics.

Basic Example · input 1

四方 C₄ 点群在 {px, py} 上的作用Tetragonal C₄ action on {px, py}

02
# 构造并检查局域基的点群表示矩阵# Construct and inspect point-group representation matrices for local bases
from magnetictb import gray, msgop, pointMatrix

identity = ((1, 0, 0), (0, 1, 0), (0, 0, 1))
point_operations = [
    operation for operation in msgop(gray[75])
    if operation[-1] == "F"
]
matrices = pointMatrix(point_operations, ("px", "py"), identity)
for matrix in matrices:
    print(matrix)
