Reference Page

fittingTB

在 Rust 中把参数仿射 Hamiltonian 拟合到参考能带，并返回参数、损失、选择掩码和比较数据。

Fit an affine-parameter Hamiltonian to reference bands in Rust, returning parameters, losses, selections, and comparison data.

01

fittingTB(h, eigdata, krange, initparms, *, MaxIterations=100, TimeConstraint=60, EnergyWindow=None, KPointNeighborhood=None, BandSelection=None, ResidualWeights=None, FiniteDifferenceStep=1e-5, InitialDamping=1e-3, FitTolerance=1e-8, HermitianTolerance=1e-10) → BandFittingResult

参数Parameter默认值Default作用Purpose
h—参数仿射的符号 Hamiltonian。Parameter-affine symbolic Hamiltonian.
eigdata—参考 k 点与能带记录。Reference k-point and band records.
krange—参与拟合的非空 1-based k 点编号序列。Nonempty sequence of 1-based k-point indices used in fitting.
initparms—必须覆盖全部 Hamiltonian 参数的初值映射或有序规则。Initial mapping or ordered rules covering every Hamiltonian parameter.
MaxIterations100优化迭代次数上限，必须是整数。Maximum optimizer iterations; must be an integer.
TimeConstraint60秒级时间上限；None 表示不设置时间限制。Time limit in seconds; None disables the time limit.
EnergyWindowNoneNone/"All" 使用全部能量，或给出 (minimum, maximum)。None/"All" uses all energies, or supply (minimum, maximum).
KPointNeighborhoodNoneNone/"All" 使用全部 k 点；也可给出含 Center 以及 Radius 或 Range 的映射。None/"All" uses all k points; otherwise provide a mapping with Center and exactly one of Radius or Range.
BandSelectionNoneNone/"All" 使用全部带；也可给出严格递增的 1-based 编号、单个编号或 BandSpan。None/"All" uses all bands; otherwise use strictly increasing 1-based indices, one index, or BandSpan.
ResidualWeightsNoneNone/"Automatic" 使用自动权重；显式数组必须与参考数据形状相同且非负。None/"Automatic" uses automatic weights; an explicit array must match reference-data shape and be nonnegative.
FiniteDifferenceStep1e-5优化器使用的有限差分步长。Finite-difference step used by the optimizer.
InitialDamping1e-3初始阻尼参数。Initial damping parameter.
FitTolerance1e-8优化收敛容差。Optimizer convergence tolerance.
HermitianTolerance1e-10参考比较中每个模型矩阵的 Hermitian 检查容差。Hermiticity tolerance for every model matrix used in the comparison.

krange 和 BandSelection 使用 1-based 物理编号；used_k_point_indices 也以 1-based 形式显示。

krange and BandSelection use 1-based physical numbers; used_k_point_indices is also displayed 1-based.
