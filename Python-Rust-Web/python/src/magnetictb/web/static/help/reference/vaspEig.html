vaspEig

读取 VASP EIGENVAL 的指定自旋通道和能带范围，并减去费米能。

Read one spin channel and a selected band interval from VASP EIGENVAL, subtracting the Fermi energy.

01

vaspEig(filename, efermi, spin, startband, endband) → list[[kpoint, energies], ...]

参数Parameter默认值Default作用Purpose
filename必填requiredEIGENVAL 的字符串或 Path 路径。String or Path pointing to EIGENVAL.
efermi必填required从所有返回能量中减去的有限实数费米能。Finite real Fermi energy subtracted from every returned energy.
spin必填required要读取的 1-based 自旋通道整数。1-based integer spin channel to read.
startband, endband必填required包含端点的 1-based VASP 能带范围。Inclusive 1-based VASP band interval.

能带编号沿用 VASP 的 1-based 物理编号；Python 外层列表和后续数组索引仍为 0-based。

Band numbers keep VASP's 1-based physical convention; subsequent Python list indices remain 0-based.

Basic example · inputs 1–3

稳定 EIGENVAL 的三条带Three bands from the stable EIGENVAL

02

读取第 21–23 条能带并显示首条记录Read bands 21–23 and show the first record

# 读取第 21–23 条能带并显示首条记录# Read bands 21–23 and show the first record
from pathlib import Path
from magnetictb import vaspEig

eigenval_file = Path("/path/to/EIGENVAL")
vasp_bands = vaspEig(eigenval_file, -0.0072, 1, 21, 23)
print(vasp_bands[0])
[[0.0, 0.0, 0.0], [-0.337773, 2.612089, 2.612105]]

发布包应把路径指向随示例提供的同一份完整数值 EIGENVAL；解析器不会执行文件内容或修补不完整记录。

A packaged example should point to the same complete numeric EIGENVAL distributed with it. The parser neither executes file contents nor repairs incomplete records.

检查返回结构Inspect the return shape

# 检查返回结构# Inspect the return shape
print((len(vasp_bands), len(vasp_bands[0]), len(vasp_bands[0][0])))
(90, 2, 3)

返回形状 (90, 2, 3) 表示 90 个 [3 维 k 点, 3 个能量] 记录，而不是扁平 90×3 数组。

Shape (90, 2, 3) means 90 records of [3D k point, three energies], not a flat 90-by-3 array.
