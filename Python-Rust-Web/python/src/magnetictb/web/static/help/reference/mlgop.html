mlgop

从随包 stable Data 读取磁层群的完整有序操作列表。每条记录为 [label, rotation, translation, "F"/"T"]。

Read a complete ordered magnetic-layer-group operation list from bundled stable Data. Every record is [label, rotation, translation, "F"/"T"].

01

mlgop(group) → list[list]

参数Parameter默认值Default作用Purpose
group必填required非空 stable ID，或 graylayer 等公开映射返回的整数编号序列。A nonempty stable ID or an integer identifier sequence returned by a public mapping such as graylayer.

group 可以是非空 stable ID 字符串，或 graylayer 等公开映射返回的整数编号序列。函数返回完整、有序、可直接传给 init 的操作表。

group may be a nonempty stable-ID string or an integer identifier sequence returned by public mappings such as graylayer. The result is a complete ordered operation table accepted by init.
