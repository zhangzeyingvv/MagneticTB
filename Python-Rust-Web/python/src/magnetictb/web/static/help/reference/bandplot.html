bandplot

沿分段 k 路径计算并绘制能带；返回可显示、保存图形的结果对象，同时保留完整数值数据。

Compute and plot bands along a segmented k path. The result displays and saves figures while retaining complete numerical data.

01

bandplot(pathstr, npoint, ham, rules=(), *, HermitianTolerance=1e-10, **plot_options) → BandPlotResult

参数Parameter默认值Default作用Purpose
pathstr—非空分段 k 路径；也可用 "Automatic" 选择当前模型的标准路径。Nonempty segmented k path, or "Automatic" for the current model’s standard path.
npoint—每段路径的正整数细分数。Positive subdivision count per segment.
ham—待数值化的 Hamiltonian。Hamiltonian to evaluate numerically.
rules()Hamiltonian 参数的数值规则。Numerical rules for Hamiltonian parameters.
HermitianTolerance1e-10Rust 本征值求解前的非负 Hermitian 检查容差。Nonnegative Hermiticity tolerance checked before Rust eigenvalue evaluation.
plotRange"All"纵轴范围：自动显示全部数据，或给定 (最小值, 最大值)。Y-axis range: show all data automatically, or supply (minimum, maximum).
yTicks"Automatic"自动刻度、刻度位置序列或 (位置, 标签) 序列；None 隐藏刻度。Automatic ticks, tick positions, or (position, label) pairs; None hides ticks.
FontSize24坐标轴刻度标签的字体大小。Font size of axis tick labels.
FontFamily"Times"刻度标签字体；Times 和 Helvetica 使用可移植的衬线与无衬线字体族。Tick-label font; Times and Helvetica use portable serif and sans-serif families.
ImageSize"Automatic"默认 640×420；可给正数宽度或 (宽度, 高度)。Default 640×420; supply a positive width or (width, height).

返回字段Returned fields

字段Field内容Content
segment_points每段包含两端点的分数倒空间采样点。Fractional reciprocal samples, including both endpoints per segment.
eigenvaluespoint-major、按能量升序的本征值。Point-major eigenvalues sorted by energy.
bands同一数据转置为 band-major。The same data transposed to band-major form.
boundary_labels路径边界标签；不连续段使用 X|M。Boundary labels; disconnected labels use X|M.

In scripts, use result.show() to display it or result.savefig("figure.svg") to save it. result.plot() returns a Matplotlib Axes; numerical fields and to_dict() remain available.

Basic examples · inputs 1–2

显式路径的完整返回值Complete return for an explicit path

02

准备模型、Hamiltonian 函数与显式路径Prepare the model, Hamiltonian function, and explicit path

# 准备模型、Hamiltonian 函数与显式路径# Prepare the model, Hamiltonian function, and explicit path
import math
from magnetictb import bandplot, init

identity = ((1, 0, 0), (0, 1, 0), (0, 0, 1))
init(
    lattice=identity,
    wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
    symminformation=(("E", identity, (0, 0, 0), "F"),),
    basisFunctions=(("s",),),
    InitialBondShells=1,
)

def plot_hamiltonian(momentum):
    kx, ky, kz = momentum
    return [[math.cos(kx) + math.cos(ky) + math.cos(kz)]]

plot_path = (
    (((0, 0, 0), (0, 0.5, 0)), (r"\Gamma", "X")),
    (((0, 0.5, 0), (0.5, 0.5, 0)), ("X", "M")),
)

当前 Python 公共入口用返回数值矩阵的 callable 定义测试 Hamiltonian。

The Python public entry defines the test Hamiltonian as a callable returning a numerical matrix.

沿显式路径计算能带Evaluate bands along the explicit path

# 沿显式路径计算能带# Evaluate bands along the explicit path
result = bandplot(plot_path, 6, plot_hamiltonian)
print(result.boundary_labels, result.boundary_positions)
print([round(values[0], 6) for values in result.eigenvalues])
# 保存本函数生成的图；交互显示可用 .show()# Save the function-generated figure; use .show() for interactive display
result.savefig("bandplot-basic.svg")

Automatic path · example 3

自动标准路径Automatic standard path

03
bandplot("Automatic", ...) 使用当前模型的标准路径；也可使用简便入口 showband。bandplot("Automatic", ...) uses the current model’s standard path; showband is a convenient alternative.
# 计算并检查分段路径上的能带数据# Compute and inspect band data along a segmented path
from magnetictb import showband

automatic = showband(4, plot_hamiltonian)
print(automatic.boundary_labels, automatic.boundary_positions)
print([round(values[0], 6) for values in automatic.eigenvalues])

print(candidate.eigenvalues == bandplot(plot_path, 4, plot_hamiltonian).eigenvalues)
