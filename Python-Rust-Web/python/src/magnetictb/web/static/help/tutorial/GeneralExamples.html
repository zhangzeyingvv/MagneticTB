MoS₂ · 三带模型three-band model

03

使用夹角为 60° 的面内晶格，在原点放置 dz2、dxy、dx2-y2 三个轨道。先把数据库中的对称操作换到该晶格坐标基，再构造 onsite 与最近邻 Hamiltonian。

Use in-plane lattice vectors at 60° and place three orbitals, dz2, dxy, and dx2-y2, at the origin. First express the database symmetry operations in this lattice basis, then construct the onsite and nearest-neighbour Hamiltonians.

from fractions import Fraction
import numpy as np
from magnetictb import (
    gray, hamiltonian_object, init, msgop, sqrt, symham,
)

# P 与其精确逆矩阵：只转换旋转部分，保留其余字段及操作顺序# P and its exact inverse: transform rotations only; retain other fields and operation order
P = np.array(((1, -1, 0), (0, 1, 0), (0, 0, 1)), dtype=object)
P_inverse = np.array(((1, 1, 0), (0, 1, 0), (0, 0, 1)), dtype=object)
mo_s2_operations = [
    [label, (P @ np.array(rotation, dtype=object) @ P_inverse).tolist(),
     translation, parity]
    for label, rotation, translation, parity in msgop(gray[187])
]

# 安装三带 MoS₂ 模型，并准备 onsite 与最近邻两个 shell# Install the three-band MoS2 model and prepare onsite and nearest-neighbour shells
init(
    lattice=((1, 0, 0), (Fraction(1, 2), sqrt(3) / 2, 0), (0, 0, 100)),
    lattpar=(),
    wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
    symminformation=mo_s2_operations,
    basis_functions=(("dz2", "dxy", "dx2-y2"),),
    initial_bond_shells=2,
    generate_symmetry_group=False,
)

# 普通用户直接得到两个完整的 3×3 二维矩阵# Ordinary users directly receive two complete 3-by-3 matrices
mo_s2_onsite = symham(1)
mo_s2_nearest = symham(2)
print(len(mo_s2_onsite), len(mo_s2_onsite[0]))

# 合并 shell 时使用高级 Hamiltonian 对象，而不是把两个 list 相加# Combine shells with advanced Hamiltonian objects, not by adding two lists
mo_s2 = hamiltonian_object(1) + hamiltonian_object(2)
print(mo_s2.parameter_names)

破缺对称与轨道顺序Broken symmetry and orbital order

04

下面两组代码均可从头运行：建立六轨道模型，选择要保留的对称操作，用返回的参数重新初始化，再计算完整的 onsite Hamiltonian。两组只改变轨道顺序，晶格、原子位置和对称性相同。

Each example runs independently: build a six-orbital model, select the symmetries to retain, reinitialize with the returned arguments, and compute the complete onsite Hamiltonian. Only the orbital order changes; the lattice, atomic position, and symmetry are identical.

brokenSymmetryInitRules((9, 11, 13)) 中的数字是原模型完整操作表中要保留的操作编号，从 1 开始，并不是要删除的编号。程序会生成它们的闭包；本例选出的三个操作仍生成完整的 24 个操作，因此本例没有降低对称性，主要用于说明重新初始化与轨道顺序的关系。

The numbers in brokenSymmetryInitRules((9, 11, 13)) are the 1-based indices of operations to retain in the original model's full operation table, not operations to remove. Their closure is generated; here these three operations generate all 24 original operations, so this example does not lower the symmetry. It illustrates reinitialization and the effect of orbital order.

顺序 A · 先按自旋分组Order A · grouped by spin

from magnetictb import (
    brokenSymmetryInitRules, gray, init, msgop, sqrt, symbol, symham,
)

# 符号晶格；a、c 的数值仅用于键搜索# Symbolic lattice; numerical a and c are used for bond search
a, c = symbol("a"), symbol("c")
# 顺序 A：先排三个自旋向上轨道，再排三个自旋向下轨道# Order A: three spin-up orbitals, followed by three spin-down orbitals
basis_a = ('dz2up', 'dxyup', 'dx2-y2up', 'dz2dn', 'dxydn', 'dx2-y2dn')
# 读取完整有序操作表，然后初始化位于原点的六轨道模型# Read the full ordered operation table, then initialize six orbitals at the origin
operations_a = msgop(gray[187])
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 4)),
    wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
    symminformation=operations_a,
    basisFunctions=(basis_a,),
    # 本例只准备 onsite 层，不包含原子间 hopping# Prepare the onsite shell only; no intersite hopping in this example
    InitialBondShells=1,
    GenerateSymmetryGroup=False,
)

# 用原模型中的 1-based 操作编号选择保留的生成元# Select retained generators by their 1-based indices in the original model
rules_a = brokenSymmetryInitRules((9, 11, 13))

# 上一步只返回参数字典；这一行才用它重新初始化当前模型# The preceding call returns arguments; this call reinitializes the current model
init(**rules_a)

矩阵的行、列均按 basis_a 的顺序排列；六个轨道都位于 (0, 0, 0)。Both matrix axes follow basis_a; all six orbitals are located at (0, 0, 0).

为什么两张矩阵看起来不同？Why do the matrices look different?

它们描述同一个模型，只是行、列的排列不同。将 A 的行和列同时按显示编号 (1, 4, 2, 5, 3, 6) 重排，就得到 B；三个独立实参数仍是 e1、e2、e3。这里的 I 表示虚数单位。

They describe the same model in different row and column orders. Reordering both axes of A by the displayed indices (1, 4, 2, 5, 3, 6) gives B. The three independent real parameters remain e1, e2, and e3; I denotes the imaginary unit.

本节输出只来自 symham(1) 的 onsite 层，所以不含动量变量，也不是含 hopping 的完整能带模型。脚本中若需要输出矩阵，将单独一行 h_a 或 h_b 改为 print(h_a) 或 print(h_b)。

These outputs contain only the onsite shell from symham(1), so there are no momentum variables; they are not hopping-inclusive band models. In a script, replace the standalone h_a or h_b expression with print(h_a) or print(h_b) to print the matrix.
