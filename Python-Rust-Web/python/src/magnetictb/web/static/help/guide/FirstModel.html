Guide · msgop → init → symham

MagneticTB 建模指南MagneticTB modeling guide

本节从一个完整且不平凡的 Graphene 模型开始，逐项说明用户输入、物理意义和实际输出。模型数据保持精确；不要把 Fraction(1, 2) 换成 0.5。

This section begins with a complete nontrivial Graphene model and explains the input, physical meaning, and actual output. Model data remain exact; do not replace Fraction(1, 2) with 0.5.

G2

完整输入Complete input

# 1. 导入精确数与建模入口# 1. Import exact-number and modeling entry points
from fractions import Fraction

from magnetictb import current_model, gray, init, msgop, sqrt, symbol

# 2. 晶格参数和分数坐标必须保持精确# 2. Keep lattice parameters and fractional coordinates exact
a = symbol("a")
c = symbol("c")
half = Fraction(1, 2)
third = Fraction(1, 3)

# 3. 读取完整且有序的磁空间群操作# 3. Read the complete ordered magnetic-space-group operations
operations = msgop(gray[191])

# 4. 安装当前模型并预先准备前三个键层# 4. Install the current model and prepare its first three shells
init(
    lattice=(
        (a, 0, 0),
        (-a * half, sqrt(3) * a * half, 0),
        (0, 0, c),
    ),
    lattpar=(("a", 1), ("c", 3)),
    wyckoffposition=(((third, 2 * third, 0), (0, 0, 0)),),
    symminformation=operations,
    basis_functions=(("pz",),),
    initial_bond_shells=3,
    generate_symmetry_group=False,
)

# 5. 核对 Hamiltonian 的轨道行列顺序# 5. Inspect the Hamiltonian row and column basis order
model = current_model()
print([(o.orbital_id, o.site_id, o.basis_function) for o in model.orbital_table])

msgop(gray[191])

返回完整、有序的磁空间群操作列表。每项严格为 [label, rotation, translation, "F"/"T"]；顺序同时固定显式表示矩阵顺序。

Returns the complete ordered magnetic-space-group operations. Each entry is [label, rotation, translation, "F"/"T"]; the order also fixes explicit representation matrices.

init(...)

成功时返回 None 并安装 context-local 当前模型。失败前清空旧会话，不会继续使用上一个模型。

Returns None and installs a context-local current model. A failed initialization clears the old session first.

symham(shell)

symham 返回指定单一键层的完整 N×N 符号 Hamiltonian，不是参数列表、维数摘要或只在 Γ 点成立的矩阵。本节给出用法、基本范例、选项和失败边界。

symham returns the complete N-by-N symbolic Hamiltonian for one shell, not a parameter list, a shape summary, or a Γ-only matrix. This section covers usage, basic examples, options, and failure boundaries.

R2

onsite = symham(1)
print(onsite)

CartesianCoordinates · 坐标变换coordinate transform

设正格矢按行组成矩阵 A，所选键的分数位移为行向量 d_frac。默认 False 使用 stable 原有的分数倒空间变量；设为 True 后，Cartesian 位移和 Bloch 相位为

Let the direct-lattice vectors be the rows of A, and let d_frac be a selected bond displacement written as a row vector. The default False uses the stable fractional-reciprocal variables. With True, the Cartesian displacement and Bloch phase are

\mathbf d_{\mathrm{cart}}=\mathbf d_{\mathrm{frac}}A, \qquad \exp\!\left(i\,\mathbf k_{\mathrm{cart}}\!\cdot\!\mathbf d_{\mathrm{cart}}\right).

这里采用 row-lattice 约定，其中 B = reciprocalLattice：

This uses the row-lattice convention, with B = reciprocalLattice:

\{k_x,k_y,k_z\} \longmapsto \bigl(2\pi\{k_x,k_y,k_z\}\bigr)B^{-1}. 
# 默认使用分数倒空间变量# Default: fractional-reciprocal variables
fractional = symham(2)
# 只改写相位坐标，不改变键层和参数# Rewrite phase coordinates without changing the shell or parameters
cartesian = symham(2, CartesianCoordinates=True)
两次调用返回相同键层、参数和矩阵维数；第二次只把每一项的相位精确改写到 Cartesian 动量。该规则已经过 Graphene 帮助例以及非正交、剪切晶格验证，并非只适用于对角晶格。Both calls return the same shell, parameters, and matrix shape; the second exactly rewrites every phase in Cartesian momentum. The rule is verified against the Graphene help example and non-orthogonal sheared lattices, not only diagonal lattices.
