Crystal, symmetry & group theory

晶体、对称性与群论Crystal, symmetry, and group theory

02

群与模型入口Groups and model entry points

  • msgop — 读取完整有序 MSG 操作。Read complete ordered MSG operations.
  • gray, bnsdict, typeI, typeIII, typeIV — 按稳定键选择磁空间群。Select magnetic space groups with stable keys.
  • graylayer, grayrod, mlgop, mrgop — 层群与杆群数据。Layer- and rod-group data.
  • init — 从局域基函数初始化。Initialize from local basis functions.
  • initfromrep — 从精确表示矩阵初始化。Initialize from exact representation matrices.

检查与构造Inspect and construct

  • showSymmetryRepresentations — 显示精确表示矩阵。Display exact representation matrices.
  • showHamiltonianBasis — 解释矩阵的 bra/ket 基。Interpret the matrix bra/ket basis.
  • brokenSymmetryInitRules, pointMatrix, getGenerator
  • showMSGWyckoff — 读取磁性 Wyckoff 表。Read magnetic Wyckoff tables.

Hamiltonian & bands

Hamiltonian 与能带计算Hamiltonians and band calculations

03
  • symham — 返回一个键层的完整普通二维符号矩阵。Return the complete ordinary two-dimensional symbolic matrix of one shell.
  • unsymham — 查看未施加对称约束的有向键矩阵。Inspect an unconstrained directed-bond matrix.
  • symhamII — 变换 Bloch 相位约定。Change the Bloch phase convention.
  • hoppingData, transformHoppings — 数值实空间 hopping 与晶胞变换。Numerical real-space hoppings and cell transforms.
  • banddata — 沿给定 k 路径计算并导出本征值。Evaluate and export eigenvalues along a k path.
  • hop, readHR — 导出与读取 Wannier90 HR，并给出真实文件内容与读回矩阵。Export and read Wannier90 HR with actual file contents and reconstructed matrices.

完整矩阵、参数名和相位示例见 symham 函数页。

See the symham page for complete matrices, parameter names, and phases.
