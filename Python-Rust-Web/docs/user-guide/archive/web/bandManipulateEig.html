bandManipulateEig

为模型参数建立不可变控件，并把每次模型求值与 VASP 参考带并列返回。

Create immutable parameter controls and return each model evaluation alongside VASP reference bands.

01

bandManipulateEig(h, eigdata, *, HermitianTolerance=1e-10) → BandFittingExplorer

参数Parameter默认值Default作用Purpose
h—包含拟合参数的符号 Hamiltonian 矩阵。Symbolic Hamiltonian matrix containing fitting parameters.
eigdata—vaspEig 兼容的参考 k 点与能带记录。vaspEig-compatible reference k-point and band records.
HermitianTolerance1e-10调用 evaluate 时使用的有限实数 Hermitian 检查容差。Finite real Hermiticity tolerance used by evaluate.

evaluate 的模型本征值由 Rust 求解；Python 只组织公共输入和不可变结果。

Rust computes model eigenvalues in evaluate; Python only organizes the public input and immutable result.

读取参考带并建立三轨道 HamiltonianRead reference bands and build the three-orbital Hamiltonian

使用 同一 EIGENVAL 三带数据，并用 gray[156] 的前六个操作生成 onsite+最近邻模型。当前 Python 必须显式写 GenerateSymmetryGroup=True。

Use the same three-band EIGENVAL data and generate an onsite-plus-nearest model from the first six gray[156] operations. Current Python requires explicit GenerateSymmetryGroup=True.

# 读取参考带并建立三轨道 Hamiltonian# Read reference bands and build the three-orbital Hamiltonian
from fractions import Fraction
from magnetictb import gray, hamiltonian_object, init, msgop, sqrt, symbol, vaspEig

vasp_bands = vaspEig("/path/to/EIGENVAL", -0.0072, 1, 21, 23)
a, c = symbol("a"), symbol("c")
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 10)),
    wyckoffposition=(((Fraction(2, 3), Fraction(1, 3), 0), (0, 0, 0)),),
    symminformation=msgop(gray[156])[:6],
    basisFunctions=(("dz2", "dxy", "dx2-y2"),),
    InitialBondShells=3,
    GenerateSymmetryGroup=True,
)
fitting_hamiltonian = hamiltonian_object(1) + hamiltonian_object(2)
print(fitting_hamiltonian.shape)
print(fitting_hamiltonian.parameter_names)

建立控件并显式求值Create controls and evaluate explicitly

# 建立控件并显式求值# Create controls and evaluate explicitly
from magnetictb import bandManipulateEig

explorer = bandManipulateEig(fitting_hamiltonian, vasp_bands)
print(explorer.parameter_names)
print(dict(explorer.defaults()))
print(len(explorer.k_points), len(explorer.reference_bands))

trial = explorer.evaluate({
