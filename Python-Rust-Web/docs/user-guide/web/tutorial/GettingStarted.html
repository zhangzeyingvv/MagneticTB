石墨烯的五类物理输入Five physical inputs for Graphene

01
Input含义Meaning
lattice按行存储三条正格矢。Three row lattice vectors.
lattpar键搜索使用的晶格符号数值。Numerical values of lattice symbols used by bond search.
wyckoffposition不等价种子的分数坐标与磁矩。Fractional seeds and magnetic moments.
symminformation完整有序磁群操作。Complete ordered magnetic-group operations.
basisFunctions每个 Wyckoff 轨道的有序局域基。Ordered local basis for each Wyckoff orbit.
# 导入精确有理数和建模函数# Import exact rational numbers and modeling functions
from fractions import Fraction
from magnetictb import gray, init, msgop, sqrt, symbol

# 晶格参数保持为符号；q 用于书写精确分数坐标# Keep lattice parameters symbolic; q creates exact fractional coordinates
a, c = symbol("a"), symbol("c")
q = Fraction

# 安装 Graphene 模型，并准备 onsite、最近邻和次近邻三层# Install the Graphene model and prepare onsite, nearest, and next-nearest shells
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 3)),
    wyckoffposition=(((q(1, 3), q(2, 3), 0), (0, 0, 0)),),
    symminformation=msgop(gray[191]),
    basisFunctions=(("pz",),),
    InitialBondShells=3,
    GenerateSymmetryGroup=False,
)

    lattice=((a, 0, 0), (0, a, 0), (0, 0, a)),

初始化自旋空间群模型Initialize the spin-space-group model

from magnetictb import SpinSpaceOperation

identity = ((1, 0, 0), (0, 1, 0), (0, 0, 1))
c4z = ((0, -1, 0), (1, 0, 0), (0, 0, 1))
# 第一个生成元旋转自旋；第二个生成元含半格矢且为反幺正# The first generator rotates spin; the second is antiunitary with a half translation
operations = (
    SpinSpaceOperation("C4spin", identity, (0, 0, 0), c4z),
    SpinSpaceOperation(
        "tauHalfT", identity, (Fraction(1, 2), 0, 0), identity,
        antiunitary=True,
    ),
)
# sup、sdn 是内置自旋基标签# sup and sdn are built-in spin-basis labels
init(
    lattice=((a, 0, 0), (0, a, 0), (0, 0, a)),
    lattpar=(("a", 1),),
    wyckoffposition=(((0, 0, 0), (0, 0, 1)),),
    symminformation=operations,
    basisFunctions=(("sup", "sdn"),),
    InitialBondShells=2,
    GenerateSymmetryGroup=True,
)
collinear = hamiltonian_object(1) + hamiltonian_object(2)

)
