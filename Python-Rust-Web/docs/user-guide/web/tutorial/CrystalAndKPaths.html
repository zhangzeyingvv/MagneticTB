从一个旋量建立磁性 Kagome 模型Build a magnetic Kagome model from one spinor

01

本教程依次生成晶体、磁矩箭头、倒空间路径、Hamiltonian 和能带。它们都来自同一个 BNS 191.239 模型；a=1、c=4。

Generate the crystal, moment arrows, reciprocal path, Hamiltonian, and bands in sequence. All use one BNS 191.239 model, with a=1 and c=4.

初始化与轨道顺序Initialization and orbital order

# 只在参考格点输入一个二分量旋量# Supply one two-component spinor at the reference site
from fractions import Fraction
from magnetictb import ExplicitPolynomialBasis, init, msgop
from magnetictb import orbitalTable, root_of_unity, sqrt, symbol, typeIII

a, c = symbol("a"), symbol("c")
# q = 1/sqrt(2)，用精确单位根表示常数系数# q = 1/sqrt(2), encoded as an exact root-of-unity coefficient
q = (root_of_unity(8, 1) + root_of_unity(8, -1)) / 2
local_spinor = ExplicitPolynomialBasis(((q, -q),))

init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 4)),
    wyckoffposition=(((Fraction(1, 2), 0, 0), (1, 0, 0)),),
    symminformation=msgop(typeIII[(191, 239)]),
    basisFunctions=local_spinor,
    RepresentationMode="Induced",
    InitialBondShells=2,
)
# 按 Hamiltonian 的行列顺序查看生成的三个格点# Inspect the three generated sites in Hamiltonian row/column order
for row in orbitalTable().to_dict()["rows"]:
    print(row["HamiltonianIndex"], row["FractionalPosition"])

三个 Cartesian 磁矩均为单位向量，彼此相差 120°，总磁矩为零。旋量的两个分量组成一个局域态；Induced 将它搬运到三个格点，因此得到三个 Hamiltonian 基态。

The three Cartesian moments are unit vectors separated by 120°, with zero net moment. The two spinor components form one local state. Induced transports it to three sites, giving three Hamiltonian basis states.

显示 2 × 2 个晶胞Display 2 × 2 cells

# CellRange 包含上下界；四个晶胞共 12 个原子# CellRange includes both bounds; four cells contain 12 atoms
from magnetictb import showCrystalStructure

crystal = showCrystalStructure(CellRange=((0, 1), (0, 1), (0, 0)), MomentScale=0.3, ImageSize=400)
print(crystal.atom_count, crystal.magnetic_atom_count)
for atom in crystal.atom_records[:3]:
    print(atom.equivalent_index, tuple(round(v, 6) for v in atom.cartesian_moment))
# 保存本函数生成的图；交互显示可用 .show()# Save the function-generated figure; use .show() for interactive display
crystal.savefig("kagome-crystal.svg")

# standardKPath 根据当前晶格返回倒空间分数坐标# standardKPath returns fractional reciprocal coordinates for the current lattice
from magnetictb import standardKPath

kagome_path = standardKPath()
for endpoints, labels in kagome_path:
    print(labels)

标准路径包含面内与 kz≠0 的分段，由晶格决定；此步骤不需要 hopping 参数。

The lattice determines a path containing in-plane and nonzero-kz segments. This step needs no hopping parameters.

取 Γ–M–K–Γ 三段Select Γ–M–K–Γ

# 后续布里渊区和能带使用同一条面内路径# Use one in-plane path for the Brillouin zone and bands
plane_path = kagome_path[:3]
for endpoints, labels in plane_path:
    print(labels, endpoints)

onsite 与最近邻矩阵Onsite and nearest-neighbour matrices

# symham 返回单个键层的普通矩阵；对象入口用于相加# symham returns a single-shell matrix; use the object entry to add shells
from magnetictb import hamiltonian_object, symham

onsite = symham(1)
for row in onsite:
    print(row)
# 合并 onsite 与所需的非零距离键层，再取普通矩阵# Combine onsite and the required hopping shells, then obtain an ordinary matrix
hamiltonian = hamiltonian_object(1) + hamiltonian_object(2)
H = hamiltonian.to_list()
for row in H:
    print(row)

[t1*exp(I*((-1/2)*kx + (-1/2)*ky)) + t1*exp(I*((1/2)*kx + (1/2)*ky)), e1, -1*t1*exp(I*((-1/2)*kx)) - 1*t1*exp(I*((1/2)*kx))]
[t1*exp(I*((-1/2)*ky)) + t1*exp(I*((1/2)*ky)), -1*t1*exp(I*((-1/2)*kx)) - 1*t1*exp(I*((1/2)*kx)), e1]

对实数 kx、ky，合并程序输出中的正反向指数项，得到完整矩阵：

For real kx and ky, combining the exponential pairs in the program output gives the full matrix:

H(\mathbf k)=\begin{pmatrix} e_1 & 2t_1\cos\frac{k_x+k_y}{2} & 2t_1\cos\frac{k_y}{2}\\ 2t_1\cos\frac{k_x+k_y}{2} & e_1 & -2t_1\cos\frac{k_x}{2}\\ 2t_1\cos\frac{k_y}{2} & -2t_1\cos\frac{k_x}{2} & e_1 \end{pmatrix}

e1 是公共 onsite 能量，t1 是最近邻参数。第 (2,3) 元的相对负号来自诱导旋量基。这里没有层间 hopping，所以矩阵不含 kz。

e1 is the common onsite energy and t1 the nearest-neighbour parameter. The relative minus sign in entry (2,3) comes from the induced spinor basis. These shells have no interlayer hopping, so the matrix has no kz dependence.

计算三条能带Compute all three bands

# 用最近邻 hopping 大小作为能量单位# Measure energy in units of the nearest-neighbour hopping magnitude
from magnetictb import bandplot

bands = bandplot(plane_path, 60, H, {"e1": 0, "t1": -1})
print(bands.boundary_labels, bands.boundary_positions)
for label, index in zip(bands.boundary_labels, (0, 60, 121, 182)):
    print(label, [round(v, 6) for v in bands.eigenvalues[index]])
# 保存本函数生成的图；交互显示可用 .show()# Save the function-generated figure; use .show() for interactive display
bands.savefig("kagome-nearest-bands.svg")
