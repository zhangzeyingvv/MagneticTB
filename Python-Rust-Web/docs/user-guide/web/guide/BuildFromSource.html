从源码构建Build from source

只有需要修改程序或没有匹配的 wheel 时才需要本页。普通用户请直接安装 wheel。

Use this page only to modify the program or when no matching wheel is available. Most users should install a wheel.

S

从源码构建前需要什么Source-build requirements

组件Component要求与用途Requirement and purpose
CPython3.9 或更高版本；建立虚拟环境并运行 Python binding。3.9 or newer; creates the virtual environment and runs the Python binding.
rustupRust toolchain 管理器；安装和更新 stable Rust（1.85 或更高版本）。Rust toolchain manager; installs and updates stable Rust (1.85 or newer).
rustc / Cargo编译 Rust 核心并解析 Cargo.lock 中固定的 crate 依赖。Compiles the Rust core and resolves crate dependencies locked by Cargo.lock.
maturin==1.14.1调用 Cargo 构建 Python extension，并安装开发版本或生成 wheel。Invokes Cargo to build the Python extension and installs a development build or creates a wheel.
系统编译工具Platform compiler toolsWindows 使用 MSVC，macOS 使用 Xcode Command Line Tools，Linux 使用 GCC/Clang、linker 和 Python headers。MSVC on Windows, Xcode Command Line Tools on macOS, and GCC/Clang, a linker, and Python headers on Linux.
下面三种系统最终都在仓库的 python 目录运行 Maturin。不要在仓库根目录直接运行这些命令。All three platforms ultimately run Maturin from the repository's python directory. Do not run these commands from the repository root.
⊞
Windows 10 / 11

PowerShell + MSVC

  1. 从 Python 官方网站安装 64 位 CPython 3.9+；打开新的 PowerShell 检查：Install 64-bit CPython 3.9+ from the official Python site, then open a new PowerShell: 
    # 检查 Windows Python 的版本与 CPU 架构# Check the Windows Python version and CPU architecture
py -3 --version
py -3 -c "import platform; print(platform.machine())"
  2. 安装 Visual Studio Build Tools，选择 Desktop development with C++，并保留 MSVC 与 Windows SDK。Install Visual Studio Build Tools, select Desktop development with C++, and keep MSVC and the Windows SDK.
  3. 从 rustup.rs 下载并运行 rustup-init.exe，选择默认 stable toolchain。关闭并重新打开 PowerShell：Download and run rustup-init.exe from rustup.rs, choose the default stable toolchain, and reopen PowerShell: 
    # 启用 stable Rust，并确认 rustup、rustc 与 Cargo 版本# Enable stable Rust and verify the rustup, rustc, and Cargo versions
rustup default stable
rustup show active-toolchain
rustc --version
cargo --version
  4. 进入源码的 python 目录并构建安装：Enter the source python directory and build: 
    # 进入 python 目录，创建虚拟环境并编译 release binding# Enter the python directory, create a virtual environment, and build the release binding
cd C:\path\to\MagneticTB-Rust-Python\python
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install maturin==1.14.1
.venv\Scripts\maturin.exe develop --release --locked
●
macOS

Terminal + Xcode

  1. 安装 Apple Command Line Tools：Install Apple Command Line Tools: 
    # 安装 macOS 编译 Rust 扩展所需的命令行工具# Install the macOS command-line tools required to compile the Rust extension
xcode-select --install
  2. 准备 CPython 3.9+；如果终端没有 python3，从 Python 官方 macOS 下载页安装。Apple Silicon 使用 arm64 Python，Intel Mac 使用 x86_64 Python；Python 与 Rust 必须采用相同架构：Prepare CPython 3.9+; if python3 is unavailable, install it from the official macOS downloads. Use arm64 Python on Apple Silicon and x86_64 Python on Intel; Python and Rust must use the same architecture: 
    # 检查 Python 与本机编译器版本# Check the Python and native compiler versions
python3 --version
python3 -c 'import platform; print(platform.machine())'
  3. 使用 Rust 官方安装器安装 stable Rust；rustup 已经包含 Cargo：Install stable Rust with the official installer; rustup includes Cargo: 
    # 安装 stable Rust 与 Cargo，并检查工具链版本# Install stable Rust and Cargo, then verify the toolchain versions
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
rustup default stable
rustc --version
cargo --version
  4. 进入 python 目录并构建安装：Enter the python directory and build: 
    # 进入 python 目录，创建虚拟环境并编译 release binding# Enter the python directory, create a virtual environment, and build the release binding
cd /path/to/MagneticTB-Rust-Python/python
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install maturin==1.14.1
.venv/bin/maturin develop --release --locked
⌘
Linux / WSL

GCC + rustup

  1. 先安装 C/C++ 编译器、linker、Python headers 和虚拟环境支持：Install a C/C++ compiler, linker, Python headers, and virtual-environment support: 
    # Ubuntu / Debian / WSL：安装编译器和 Python 开发文件# Ubuntu / Debian / WSL: install the compiler and Python development files
sudo apt update
sudo apt install -y build-essential curl python3 python3-dev python3-venv

# Fedora / RHEL：对应的软件包名称# Fedora / RHEL: corresponding package names
sudo dnf install -y gcc gcc-c++ make curl python3 python3-devel
  2. 安装 stable Rust 与 Cargo：Install stable Rust and Cargo: 
    # 安装 stable Rust 与 Cargo，并检查工具链版本# Install stable Rust and Cargo, then verify the toolchain versions
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
rustup default stable
rustc --version
cargo --version
  3. 确认 Python 不低于 3.9：Confirm Python is at least 3.9: 
    # 检查 Python 与本机编译器版本# Check the Python and native compiler versions
python3 --version
cc --version
  4. 进入 python 目录并构建安装。WSL 也使用同一组 Linux 命令和 .venv/bin/ 路径：Enter the python directory and build. WSL uses the same Linux commands and .venv/bin/ paths: 
    # 进入 python 目录，创建虚拟环境并编译 release binding# Enter the python directory, create a virtual environment, and build the release binding
cd /path/to/MagneticTB-Rust-Python/python
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install maturin==1.14.1
.venv/bin/maturin develop --release --locked

在 Conda 环境中编译Build in a Conda environment

先按对应系统准备 Rust 和系统编译工具。Conda 可以替代上面的 Python 与 .venv 环境步骤，但不能替代 Rust 或 linker。Windows 使用已启用 Conda 的终端，macOS / Linux 同理：

Prepare Rust and the platform build tools first. Conda replaces the Python and .venv setup above, not Rust or the linker. Use a Conda-enabled terminal on any platform:

# 已有同名环境时跳过创建，只激活环境# Skip creation if the named environment exists; activate it instead
conda create -n magnetictb --override-channels -c conda-forge python=3.12 pip
conda activate magnetictb

# 从仓库根目录进入 python，并编译到当前 Conda 环境# From the repository root, enter python and build into the active Conda environment
cd python
python -m pip install "maturin==1.14.1"
python -m maturin develop --release --locked

# 检查安装并启动 Web# Check the installation and start Web
python -c "import magnetictb; print(magnetictb.__version__)"
magnetictb-web

若需生成 wheel，在同一环境的 python/ 目录使用 python -m maturin build --release --locked --out dist。

To create a wheel, use python -m maturin build --release --locked --out dist from python/ in the same environment.

生成可分发 wheelBuild a distributable wheel

maturin develop 适合当前源码环境；需要交给其他用户安装时，在已经准备好的同一环境运行：

maturin develop is for the current source environment. To produce a wheel for another user, run:

# macOS / Linux / WSL：在当前虚拟环境构建 wheel# macOS / Linux / WSL: build a wheel in the current virtual environment
.venv/bin/maturin build --release --locked --out dist

# Windows PowerShell：使用对应的 maturin 可执行文件# Windows PowerShell: use the corresponding maturin executable
.venv\Scripts\maturin.exe build --release --locked --out dist

生成文件位于 python/dist/。wheel 只能安装到与其平台、CPU 架构和 Python ABI 匹配的环境；安装该 wheel 的用户不再需要 Rust。

The wheel is written to python/dist/. It can only be installed on a matching platform, CPU architecture, and Python ABI; wheel users no longer need Rust.
