Guide · Installation

MagneticTB 安装Install MagneticTB

选择一种安装方式：venv、Conda 或源码构建。前两种方式安装预编译 wheel，不需要 Rust；只有源码构建需要编译工具。

Choose one installation method: venv, Conda, or a source build. The first two install a prebuilt wheel without Rust; only source builds require compiler tools.

G1

方式一：venv 安装Method 1: Install with venv

wheel 已经包含编译后的 Rust 核心及其 Rust crate 依赖。普通用户不需要另外安装 Rust、Cargo 或 Maturin。A wheel already contains the compiled Rust core and its Rust crate dependencies. End users do not install Rust, Cargo, or Maturin separately.

Windows PowerShell

# 创建环境并安装 wheel# Create an environment and install the wheel
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install ".\magnetictb-0.1.0-cp39-abi3-PLATFORM.whl"

# 检查安装，然后启动本地 Web 工作台# Check the installation, then start the local Web workbench
.venv\Scripts\python.exe -c "import magnetictb; print(magnetictb.__version__)"
.venv\Scripts\magnetictb-web.exe

macOS / Linux / WSL

# 创建环境并安装 wheel# Create an environment and install the wheel
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install "./magnetictb-0.1.0-cp39-abi3-PLATFORM.whl"

# 检查安装，然后启动本地 Web 工作台# Check the installation, then start the local Web workbench
.venv/bin/python -c "import magnetictb; print(magnetictb.__version__)"
.venv/bin/magnetictb-web

服务启动后，浏览器打开 http://127.0.0.1:8000/。下次使用时，在同一目录直接运行对应系统的 magnetictb-web 启动命令，无需重复安装。

Once the server starts, open http://127.0.0.1:8000/. Next time, run the corresponding magnetictb-web launcher from the same directory; no reinstallation is needed.

当前尚未发布到 PyPI，因此不要使用未经提供的 pip install magnetictb 下载命令。

The package is not yet published on PyPI, so do not use an unprovided pip install magnetictb download command.

方式二：Conda 安装Method 2: Install with Conda

已有 Conda 可以直接使用；尚未安装时可按 Miniforge 官方说明安装与你的系统和 CPU 匹配的版本。Windows 打开 Miniforge Prompt（或已有的 Anaconda Prompt）；macOS / Linux 打开已启用 Conda 的终端。

Use an existing Conda installation, or follow the official Miniforge instructions for your OS and CPU. On Windows, open Miniforge Prompt (or an existing Anaconda Prompt); on macOS / Linux, use a Conda-enabled terminal.

# 创建独立环境；如果已有 magnetictb 环境，跳过创建这一步# Create an isolated environment; skip creation if magnetictb already exists
conda create -n magnetictb --override-channels -c conda-forge python=3.12 pip
conda activate magnetictb

# 在 wheel 所在目录运行；将 PLATFORM 替换为实际平台标记# Run in the wheel directory; replace PLATFORM with its actual platform tag
python -m pip install "./magnetictb-0.1.0-cp39-abi3-PLATFORM.whl"

# 检查当前环境能否加载 MagneticTB，再启动网页# Check the MagneticTB import in this environment, then start the Web UI
python -c "import magnetictb; print(magnetictb.__version__)"
magnetictb-web

浏览器打开 http://127.0.0.1:8000/。以后重新打开终端，只需先执行 conda activate magnetictb，再运行 magnetictb-web。

Open http://127.0.0.1:8000/. In a new terminal, run conda activate magnetictb before magnetictb-web.

这条路线由 Conda 管理 Python 环境、pip 安装本地 wheel 和 Web 依赖，不需要再创建 .venv，也不需要 Rust。

Conda manages Python, while pip installs the local wheel and Web dependencies. Do not create another .venv; wheel installation needs no Rust.

方式三：源码构建Method 3: Build from source

需要修改程序或没有与你的系统匹配的 wheel 时，选择源码构建。先准备 Python、Rust toolchain、Cargo 和系统编译工具，再构建并安装。

Choose a source build if you need to modify the program or no wheel matches your system. Prepare Python, the Rust toolchain, Cargo, and platform compiler tools, then build and install.

Windows、macOS、Linux 的环境准备与完整构建步骤 →Requirements and complete build steps for Windows, macOS, and Linux →

Installation · package management

更新、卸载与检查安装Update, uninstall, and check the installation

以下命令中的 python 指已安装 MagneticTB 的环境：Conda 用户先激活环境；venv 用户使用对应的 .venv Python 路径。

Here python means the environment where MagneticTB is installed: activate it for Conda, or use its .venv Python path.

常用 Python 安装命令Common Python installation commands

# 把 PLATFORM 替换为与你的 Python 和系统匹配的实际文件名# Replace PLATFORM with the filename matching your Python and operating system
python -m pip install ./magnetictb-0.1.0-PLATFORM.whl
Successfully installed magnetictb-0.1.0

实际 wheel 文件名必须匹配当前 Python 和操作系统。

The wheel filename must match the current Python and operating system.

# 用新 wheel 覆盖当前安装# Replace the current installation with a new wheel
python -m pip install --force-reinstall ./magnetictb-0.1.0-PLATFORM.whl

用于更新或重新安装同一环境中的软件包。

Use this to update or reinstall the package in the same environment.

# 从当前 Python 环境卸载# Uninstall from the current Python environment
python -m pip uninstall magnetictb
# 常用 Python 安装命令# Common Python installation commands
import magnetictb
print(magnetictb.__version__)
0.1.0
