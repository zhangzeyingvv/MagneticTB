brokenSymmetryInitRules

从当前模型选择保留子群，拆分必要的 site orbit，并返回可直接交给 init(**rules) 的参数字典。

Select a retained subgroup of the current model, split site orbits as required, and return a dictionary ready for init(**rules).

01

brokenSymmetryInitRules(selector) → dict

参数Parameter默认值Default作用Purpose
selector必填required接受 "All"、正整数、非空标签或其序列。"All" 保留完整操作表；整数按 1-based 操作编号解释；字符串按操作标签解释。Accepts "All", positive integers, nonempty labels, or their sequences. "All" retains the full operation table; integers are 1-based operation indices and strings are operation labels.

函数读取当前会话，而且当前模型必须保留原始 init recipe；返回字典不会自动重新安装模型。

The function reads the current session and requires the model's original init recipe; the returned dictionary does not reinstall the model automatically.

# 生成并使用破缺对称性模型的初始化参数# Generate and use initialization arguments for a broken-symmetry model
from fractions import Fraction
from pprint import pprint
from magnetictb import (
    brokenSymmetryInitRules, gray, init, msgop,
    sqrt, symbol,
)

a, c = symbol("a"), symbol("c")
operations = msgop(gray[191])
init(
    lattice=((a, 0, 0), (-a/2, sqrt(3)*a/2, 0), (0, 0, c)),
    lattpar=((a, 1), (c, 3)),
    wyckoffposition=(((Fraction(1, 3), Fraction(2, 3), 0), (0, 0, 0)),),
    symminformation=operations,
    basis_functions=(("pz",),),
)
rules = brokenSymmetryInitRules([2])
pprint(rules, sort_dicts=False)

# 生成并使用破缺对称性模型的初始化参数# Generate and use initialization arguments for a broken-symmetry model
init(**rules)

字典完整保留晶格、参数、拆分后的 Wyckoff 输入、六个保留操作、基底、键层数与精确域。它不修改原字典，也不会静默加入被删除的对称操作。

The dictionary retains the lattice, parameters, split Wyckoff input, six retained operations, basis, shell count, and exact field. It does not mutate the original dictionary or silently restore removed operations.
