showMSGWyckoff

返回一个磁空间群的完整稳定 Wyckoff 表，包括 multiplicity、字母、source ordinal、全部位置与磁矩方向。

Return the complete stable Wyckoff table of one magnetic space group: multiplicity, letter, source ordinal, positions, and moment directions.

01

showMSGWyckoff(group) → TableReport

参数Parameter默认值Default作用Purpose
group必填requiredstable MSG 序号、MSG(...) 或公开磁空间群 selector。A stable MSG index, MSG(...), or a public magnetic-space-group selector.

group 可为 stable MSG 序号、MSG(...) 或 gray/typeI/typeIII/typeIV 等 selector。结果顺序与 stable Data 一致，不按字母重新排序。

group may be a stable MSG index, MSG(...), or a gray/typeI/typeIII/typeIV selector. Result order follows stable Data and is not alphabetically reconstructed.

Basic Example · input 1

gray[193] · P6₃/mcm1′

02
# 读取并检查磁空间群的 Wyckoff 数据# Read and inspect Wyckoff data for a magnetic space group
from magnetictb import gray, showMSGWyckoff

report = showMSGWyckoff(gray[193])
data = report.to_dict()
print(data["title"])
print(data["metadata"])
for row in data["rows"]:
    positions = [item["Position"]
                 for item in row["AtomicPositionsAndMagnetizationDirections"]]
    print(row["Multiplicity"], row["WyckoffLetter"],
          row["SourceOrdinal"], positions)
