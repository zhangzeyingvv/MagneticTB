standardKPath

根据当前模型晶格返回稳定的高对称 k 路径。每一段写成 ((k_start, k_end), (label_start, label_end))。

Return a stable high-symmetry k path for the current model lattice. Every segment is ((k_start, k_end), (label_start, label_end)).

01

standardKPath(*, BravaisType="Automatic", Tolerance=1e-6, model=None) → tuple[BandSegment, ...]

参数Parameter默认值Default作用Purpose
BravaisType"Automatic"自动识别 Bravais 类型；也可传入已支持的类型名称以显式选择路径。Detect the Bravais type automatically, or supply a supported name explicitly.
Tolerance1e-6晶格类型识别使用的有限实数容差。Finite real tolerance used for lattice-type classification.
modelNoneNone 使用当前会话；也可传入 PreparedModel，不读取或改变会话。None uses the current session; a PreparedModel may be supplied without reading or changing that session.

# 生成并检查标准高对称 k 路径# Generate and inspect a standard high-symmetry k path
from magnetictb import gray, init, msgop, standardKPath

identity = ((1, 0, 0), (0, 1, 0), (0, 0, 1))
operations = msgop(gray[221])
init(
    lattice=identity,
    wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
    symminformation=operations,
    basis_functions=(("s",),),
    initial_bond_shells=2,
    generate_symmetry_group=False,
)
