typeIV[(n, m)]

返回 BNS 编号为 n.m 的 IV 型磁空间群 stable MSGOP 序号；该只读映射含 517 个键。

Return the stable MSGOP index of the type-IV magnetic space group with BNS number n.m; this read-only mapping contains 517 keys.

01

参数Parameter默认值Default作用Purpose
(n, m)必填required完整 BNS 编号的二整数元组；该映射只包含 517 个 IV 型磁空间群。A two-integer tuple containing the complete BNS number; this mapping contains the 517 type-IV magnetic space groups only.
