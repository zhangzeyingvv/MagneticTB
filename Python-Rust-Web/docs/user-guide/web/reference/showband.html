showbandReference Page

Reference Page

showband

用当前模型的 standardKPath() 计算能带；等价于先取自动路径，再调用 bandplot。

Evaluate bands on the current model's standardKPath(); equivalent to obtaining that automatic path and then calling bandplot.

01

showband(npoint, ham, rules=(), **options) → BandPlotResult

参数Parameter默认值Default作用Purpose
npoint—每段路径的正整数细分数。Positive subdivision count for every path segment.
ham—符号 Hamiltonian 矩阵或可在 k 点求值的兼容对象。Symbolic Hamiltonian matrix or compatible object evaluable at k points.
rules()Hamiltonian 参数的数值规则。Numerical rules for Hamiltonian parameters.
BravaisType"Automatic"传给 standardKPath 的 Bravais 类型。Bravais type forwarded to standardKPath.
Tolerance1e-6标准路径晶格分类容差。Lattice-classification tolerance for the standard path.
HermitianTolerance1e-10Rust 本征值求解前的非负 Hermitian 检查容差。Nonnegative Hermiticity tolerance checked before Rust eigenvalue evaluation.
plotRange"All"纵轴范围：自动显示全部数据，或给定 (最小值, 最大值)。Y-axis range: show all data automatically, or supply (minimum, maximum).
yTicks"Automatic"自动刻度、刻度位置序列或 (位置, 标签) 序列；None 隐藏刻度。Automatic ticks, tick positions, or (position, label) pairs; None hides ticks.
FontSize24坐标轴刻度标签的字体大小。Font size of axis tick labels.
FontFamily"Times"刻度标签字体；Times 和 Helvetica 使用可移植的衬线与无衬线字体族。Tick-label font; Times and Helvetica use portable serif and sans-serif families.
ImageSize"Automatic"默认 640×420；可给正数宽度或 (宽度, 高度)。Default 640×420; supply a positive width or (width, height).
在 Notebook 中将结果作为单元最后一行即可显示图形；脚本中用 result.show() 显示，用 result.savefig("figure.svg") 保存。result.plot() 返回 Matplotlib Axes，数值字段与 to_dict() 仍可读取。Use the result as the last expression of a notebook cell to display it. In scripts, use result.show() to display it or result.savefig("figure.svg") to save it. result.plot() returns a Matplotlib Axes; numerical fields and to_dict() remain available.

初始化并取得最近邻 HamiltonianInitialize and obtain the nearest-neighbour Hamiltonian

# 初始化并取得最近邻 Hamiltonian# Initialize and obtain the nearest-neighbour Hamiltonian
from magnetictb import gray, hamiltonian_object, init, msgop

identity = ((1, 0, 0), (0, 1, 0), (0, 0, 1))
init(
    lattice=identity,
    wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
    symminformation=msgop(gray[221]),
    basisFunctions=(("s",),),
    InitialBondShells=2,
)
hamiltonian = hamiltonian_object(2)

# 沿标准路径计算并检查能带数据# Compute and inspect band data along the standard path
from magnetictb import showband

result = showband(4, hamiltonian, {"t1": 1})
print(result.boundary_labels, result.boundary_positions)
print([round(row[0], 6) for row in result.eigenvalues])
# 保存本函数生成的图；交互显示可用 .show()# Save the function-generated figure; use .show() for interactive display
result.savefig("showband-basic.svg")
