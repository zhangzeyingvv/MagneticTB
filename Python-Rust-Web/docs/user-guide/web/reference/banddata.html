banddata

沿指定路径求本征值，按 point-major 顺序写入 UTF-8 CSV，并返回实际保存路径。

Evaluate eigenvalues along a path, write a UTF-8 point-major CSV, and return its actual path.

01

banddata(pathstr, npoint, ham, rules, save, *, HermitianTolerance=1e-10) → str

参数Parameter默认值Default作用Purpose
pathstr—非空分段 k 路径。Nonempty segmented k path.
npoint—每段路径的正整数细分数。Positive subdivision count per segment.
ham—待数值化的 Hamiltonian。Hamiltonian to evaluate numerically.
rules—Hamiltonian 参数的完整数值规则。Complete numerical rules for Hamiltonian parameters.
save—输出 CSV 的字符串或 Path 路径。String or Path target for the output CSV.
HermitianTolerance1e-10Rust 本征值求解前的非负 Hermitian 检查容差。Nonnegative Hermiticity tolerance checked before Rust eigenvalue evaluation.

每一行是一个 k 点；列按能量从低到高。每段保留首尾点，因此相邻段共同端点会出现两次，与 bandplot 完全一致。

Each row is one k point and columns are sorted by energy. Both endpoints are retained per segment, so shared boundaries appear twice, exactly as in bandplot.

02

准备 Graphene Hamiltonian、路径和临时文件Prepare the Graphene Hamiltonian, path, and temporary file

下面完整建立三键层模型，不依赖页面外的隐藏状态。

This example builds the complete three-shell model without hidden state from another page.

# 准备 Graphene Hamiltonian、路径和临时文件# Prepare the Graphene Hamiltonian, path, and temporary file
from fractions import Fraction
from pathlib import Path
from tempfile import gettempdir
from magnetictb import gray, hamiltonian_object, init, msgop, sqrt, symbol

a, c = symbol("a"), symbol("c")
q = Fraction
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 3)),
    wyckoffposition=(((q(1, 3), q(2, 3), 0), (0, 0, 0)),),
    symminformation=msgop(gray[191]),
    basisFunctions=(("pz",),),
    InitialBondShells=3,
    GenerateSymmetryGroup=False,
)
graphene_hamiltonian = (
    hamiltonian_object(1) + hamiltonian_object(2) + hamiltonian_object(3)
)
graphene_path = (
    (((0, 0, 0), (0, q(1, 2), 0)), (r"\Gamma", "M")),
    (((0, q(1, 2), 0), (q(1, 3), q(1, 3), 0)), ("M", "K")),
    (((q(1, 3), q(1, 3), 0), (0, 0, 0)), ("K", r"\Gamma")),
)
target = Path(gettempdir()) / "graphene-band.csv"

init(...) 安装当前会话并返回 None；这个 Input 的用途是准备后两个 Input 所需对象。

init(...) installs the current session and returns None; this input prepares objects used by the next two inputs.

导出取样能量Export sampled energies

# 导出取样能量# Export sampled energies
from magnetictb import banddata

saved = banddata(
    graphene_path, 10, graphene_hamiltonian,
    {"e1": 0.05, "r1": 0.02, "t1": 0.5}, target,
)
print(Path(saved).name)

绘制同一模型的能带Plot bands for the same model

banddata 保存 CSV；绘图使用 bandplot，采用相同路径、采样数和参数。

banddata saves CSV; use bandplot with the same path, sampling, and parameters to produce the figure.

# 用与 CSV 导出相同的模型和参数生成图形# Generate a figure using the same model and parameters as the CSV export
from magnetictb import bandplot

plot = bandplot(
    graphene_path, 10, graphene_hamiltonian,
    {"e1": 0.05, "r1": 0.02, "t1": 0.5},
)
# 保存本函数生成的图；交互显示可用 .show()# Save the function-generated figure; use .show() for interactive display
plot.savefig("banddata-graphene.svg")
