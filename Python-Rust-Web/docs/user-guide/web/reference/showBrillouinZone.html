showBrillouinZone

绘制第一 Brillouin 区及 k 路径，并保留顶点、面和路径数据。

Draw the first Brillouin zone and k path while retaining vertices, facets, and path data.

01

showBrillouinZone(*, KPath="Automatic", ShowKPath=True, TranslationRange=2, Tolerance=1e-8, FontSize=14, ImageSize="Large", model=None) → BrillouinZoneResult

在 Notebook 中将结果作为单元最后一行即可显示图形；脚本中用 result.show() 显示，用 result.savefig("figure.svg") 保存。result.plot() 返回 Matplotlib Axes，数值字段与 to_dict() 仍可读取。Use the result as the last expression of a notebook cell to display it. In scripts, use result.show() to display it or result.savefig("figure.svg") to save it. result.plot() returns a Matplotlib Axes; numerical fields and to_dict() remain available.
参数Parameter默认值Default作用Purpose
KPath"Automatic"自动使用 standardKPath；None 不生成路径；也可提供显式分段路径。Use standardKPath automatically, use None for no path, or provide an explicit segmented path.
ShowKPathTrue是否把路径放入显示数据，必须是 bool。Whether the path is included in display data; must be bool.
TranslationRange2构造第一 Brillouin 区时使用的正整数倒格平移范围。Positive reciprocal-translation range used to construct the first Brillouin zone.
Tolerance1e-8几何去重和边界判断使用的正实数容差。Positive real tolerance for geometric deduplication and boundary decisions.
FontSize14图中标签字体大小，必须为正实数。Font size of labels in the figure; must be a positive real number.
ImageSize"Large"实际绘图尺寸：支持预设名称、正数宽度或 (宽度, 高度)。Rendered image size: a preset name, positive width, or (width, height).
modelNoneNone 使用当前会话；也可传入独立 PreparedModel。None uses the current session; a detached PreparedModel may also be supplied.

三维图使用正交投影。result.savefig("zone.svg", elev=30, azim=15) 可指定视角；交互旋转需使用支持交互的 Matplotlib 后端。

The 3D figure uses orthographic projection. Set the view with result.savefig("zone.svg", elev=30, azim=15); mouse rotation requires an interactive Matplotlib backend.

Basic Examples

六方晶格的第一布里渊区First Brillouin zone of a hexagonal lattice

02

初始化六方晶格Initialize a hexagonal lattice

# 六方晶格：a=1、c=3/2；只需准备 onsite 层即可显示几何# Hexagonal lattice: a=1, c=3/2; preparing onsite is sufficient for geometry
from fractions import Fraction
from magnetictb import gray, init, msgop, showBrillouinZone, sqrt, symbol

a, b, c = symbol("a"), symbol("b"), symbol("c")
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", Fraction(3, 2))),
    wyckoffposition=(((Fraction(1, 3), Fraction(2, 3), 0), (0, 0, 0)),),
    symminformation=msgop(gray[191]), basisFunctions=(("pz",),),
    InitialBondShells=1,
)

读取倒格矢、顶点与面Read reciprocal vectors, vertices, and faces

# 几何由晶格决定，无需先求 Hamiltonian# The lattice determines the geometry; no Hamiltonian is needed
bz = showBrillouinZone()
print(bz.bravais_type, bz.bz_type)
print(len(bz.vertices), bz.facet_count)
print([[round(v, 6) for v in row] for row in bz.reciprocal_lattice])
# 保存本函数生成的图；交互显示可用 .show()# Save the function-generated figure; use .show() for interactive display
bz.savefig("zone-hexagonal.svg", elev=60, azim=30)

晶格向量按行存储。顶点使用 Cartesian 倒空间坐标；倒格矢包含 2π。facets 中的整数是 0-based 顶点索引。

Lattice vectors are stored as rows. Vertices use Cartesian reciprocal coordinates and reciprocal vectors include 2π. Integers in facets are 0-based vertex indices.

本页六方区采用斜俯视：elev=60, azim=30，便于同时看清六边形截面与棱柱高度。

The hexagonal-zone figures use an elevated oblique view, elev=60, azim=30, to show both the hexagonal cross-section and prism height.

03

KPathKPath

# 显式指定 kz=0 平面内的路径，端点为倒空间分数坐标# Specify an in-plane path at kz=0 using fractional reciprocal endpoints
plane_path = (
    (((0, 0, 0), (Fraction(1, 2), 0, 0)), (r"\Gamma", "M")),
    (((Fraction(1, 2), 0, 0), (Fraction(1, 3), Fraction(1, 3), 0)), ("M", "K")),
    (((Fraction(1, 3), Fraction(1, 3), 0), (0, 0, 0)), ("K", r"\Gamma")),
)
custom = showBrillouinZone(KPath=plane_path)
print(custom.bravais_type, custom.bz_type)
print(len(custom.vertices), custom.facet_count)
# 保存本函数生成的图；交互显示可用 .show()# Save the function-generated figure; use .show() for interactive display
# 沿 kz 方向俯视，清楚显示六边形和面内路径# Look down the kz direction to show the hexagon and in-plane path clearly
custom.savefig("zone-custom-path.svg", elev=90, azim=-90)
