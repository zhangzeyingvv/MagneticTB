showSymmetryRepresentations

按完整操作顺序显示 Rust 构造的精确轨道表示矩阵。

Display exact Rust-constructed orbital representation matrices in full operation order.

01

showSymmetryRepresentations(selection="Automatic", *, model=None) → TableReport

参数Parameter默认值Default作用Purpose
selection"Automatic""Automatic" 显示生成元；"All" 显示全部操作；也可给出一个或一组 1-based 操作编号。"Automatic" shows generators, "All" shows every operation, or supply one or more 1-based operation indices.
modelNoneNone 使用当前会话；也可传入独立 PreparedModel。None uses the current session; a detached PreparedModel may also be supplied.
编号必须位于当前模型完整操作表的 1-based 范围内；序列按首次出现去重并保持顺序。Indices must lie in the model's 1-based full-operation range; sequences are deduplicated in first-occurrence order.

Basic Example · input 1

Graphene 生成元表示Graphene generator representations

02

先运行 init 页的 Graphene 完整初始化，然后：

Run the complete Graphene initialization, then:

# 读取并检查当前模型的对称表示# Read and inspect symmetry representations of the current model
from magnetictb import showSymmetryRepresentations

report = showSymmetryRepresentations()
rows = report.to_dict()["rows"]
print(report.title)
for row in rows:
    print(row["OperationIndex"], row["Label"],
          row["Generator"], row["Antiunitary"], row["Matrix"])
Representation mode: DirectProduct; dimension = 2; showing 4 of 48 operations
2  6z True False [['0', '1'], ['1', '0']]
7  2x True False [['0', '-1'], ['-1', '0']]
13 -1 True False [['0', '-1'], ['-1', '0']]
25 1  True True  [['1', '0'], ['0', '1']]

第 25 个操作的矩阵虽然是单位阵，但 Antiunitary=True，作用时还要对系数复共轭。

Operation 25 has the identity matrix but Antiunitary=True, so its action also conjugates coefficients.

Applications · inputs 2–3

按序号选择操作Select operations by number

03

输入 2 · 三个指定操作Input 2 · three operations

# 三个指定操作# three operations
rows = showSymmetryRepresentations((1, 3, 25)).to_dict()["rows"]
for row in rows:
    print(row["OperationIndex"], row["Label"],
          row["Antiunitary"], row["Matrix"])
1  1  False [['1','0'],['0','1']]
3  3z False [['1','0'],['0','1']]
25 1  True  [['1','0'],['0','1']]

相同的轨道矩阵不表示相同的群作用：第 3 个操作旋转空间，第 25 个操作还执行复共轭。

Equal orbital matrices need not mean equal group actions: operation 3 rotates space, while operation 25 also conjugates coefficients.

输入 3 · 只看时间反演Input 3 · time reversal only

# 只看时间反演# time reversal only
row = showSymmetryRepresentations(25).to_dict()["rows"][0]
print(row["OperationIndex"], row["Label"],
      row["Antiunitary"], row["Matrix"])
25 1 True [['1', '0'], ['0', '1']]
