showbonds

按格点显示一个已准备键层中的全部 directed bonds。

Display all directed bonds in one prepared shell, grouped by source site.

01

showbonds(shell, *, model=None) → None

直接显示键表：Jupyter 中显示 HTML 表格，脚本或终端中输出对齐的文本表格。返回值为 None，无需赋值或手写打印循环。show_bonds 是同义名称。

Display the bond table directly: an HTML table in Jupyter, or an aligned text table in scripts and terminals. The return value is None; no assignment or printing loop is needed. show_bonds is an alias.

参数Parameter默认值Default作用Purpose
shell—1-based 已准备键层；必须位于 1..initial_bond_shells。Prepared 1-based shell in 1..initial_bond_shells.
modelNoneNone 使用当前会话；也可传入独立 PreparedModel。None uses the current session; a detached PreparedModel may also be supplied.

shell 是 1-based：第 1 层 onsite，第 2 层第一个非零距离近邻。函数只读取 init 已准备的键，不重新搜索或扩展键层。

shell is 1-based: shell 1 is onsite and shell 2 is the first nonzero-distance shell. The function only reads bonds prepared by init; it never reruns or extends the search.

Data access

需要读取数据时：bondTableFor data access: bondTable

bondTable(shell, *, model=None) → TableReport

参数、默认值和键层编号与 showbonds 相同，但不显示表格。返回完整的只读键数据，包括 title、columns、rows 和 metadata；to_dict() 转为普通 Python 数据。bond_table 是同义名称。

Arguments, defaults, and shell numbering match showbonds, but no table is displayed. Return the complete read-only bond data, including title, columns, rows, and metadata; to_dict() converts it to ordinary Python data. bond_table is an alias.

from magnetictb import bondTable
# 只在需要处理数据时读取字段；显示键表直接用 showbonds(2)# Read fields only when processing data; use showbonds(2) directly for display
data = bondTable(2).to_dict()

Properties & Relations

6 条 directed bonds 是什么Why there are six directed bonds

03

石墨烯有三条无向最近邻键。Hamiltonian 的行/列方向需要同时保存每条键及其反向键，所以表中有 6 条；它们属于一个对称性 directed orbit。

Graphene has three undirected nearest-neighbour bonds. Hamiltonian row/column orientation stores every bond and its reverse, so the report contains six directed bonds in one symmetry orbit.

\mathbf d=\mathbf r_{\mathrm{target}}+\mathbf n-\mathbf r_{\mathrm{source}},\qquad C_{-\mathbf d}=C_{\mathbf d}^{\dagger}.

距离的 f64 路径只决定拓扑与键层；表中的分数端点和整数平移来自精确 Rust 数据。

The f64 distance path determines topology and shell membership only; displayed fractional endpoints and integer translations come from exact Rust data.
