compareBand

在同一张图中叠加模型能带与参考能带：TB 为紫色，Reference 为浅蓝色。

Overlay model and reference bands in one figure: TB in purple and Reference in light blue.

01

compareBand(pathstr, npoint, ham, rules, vaspband, *, plotRange=None, HermitianTolerance=1e-10) → BandPathComparison

参数Parameter默认值Default作用Purpose
pathstr—与参考数据对应的非空分段 k 路径。Nonempty segmented k path corresponding to the reference data.
npoint—每段参考记录数；模型采样仍按 bandplot 约定包含两端点。Reference records per segment; model sampling still follows bandplot and includes both endpoints.
ham, rules—Hamiltonian 及其数值参数规则。Hamiltonian and its numerical parameter rules.
vaspband—vaspEig 兼容的参考带记录。vaspEig-compatible reference-band records.
plotRangeNone纵轴能量范围，同时用于两组曲线；None 自动覆盖两组数据。Y-axis energy limits applied to both datasets; None automatically includes both.
HermitianTolerance1e-10模型能带求解使用的非负 Hermitian 检查容差。Nonnegative Hermiticity tolerance used for model-band evaluation.

Notebook 中将返回对象作为单元最后一行即可显示叠加图；脚本中用 result.show(block=None) 显示，或 result.savefig("comparison.svg") 保存。result.plot(ax=None) 返回 Matplotlib Axes，result.to_dict() 仍提供数值数据。

Put the returned object last in a notebook cell to display the overlay. In scripts, use result.show(block=None) or result.savefig("comparison.svg"). result.plot(ax=None) returns Matplotlib Axes and result.to_dict() still provides numerical data.

compareBand 创建对象时计算模型能带；随后显示或保存只读取已有数据，不重复拟合或求解本征值。

compareBand computes model bands when creating the object. Subsequent display or export uses existing data without refitting or solving eigenvalues again.

模型每段有 npoint+1 个点；VASP 参考数据要求每段恰好 npoint 个记录。因此三段、npoint=30 时模型有 93 点，参考有 90 点。

The model has npoint+1 points per segment, while the VASP reference requires exactly npoint records per segment. For three segments and npoint=30, the model has 93 points and the reference has 90.

02

先下载本例参考数据，放到 Python 当前工作目录。文件包含由 vaspEig 读取的 90 个 k 点和三条参考带，能量以 eV 为单位。本例直接使用保存的参数，不运行拟合优化器。

Download the example reference data to your Python working directory. It contains 90 k points and three reference bands read by vaspEig, with energies in eV. This example uses saved parameters without running a fitting optimizer.

# 读取参考带，并建立包含三个键层的模型# Read reference bands and build the three-shell model
import json
from pathlib import Path
from fractions import Fraction
from magnetictb import compareBand, gray, hamiltonian_object, init, msgop, sqrt, symbol

vasp_bands = json.loads(Path("compareband-reference.json").read_text(encoding="utf-8"))["records"]
a, c = symbol("a"), symbol("c")
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 10)),
    wyckoffposition=(((Fraction(2, 3), Fraction(1, 3), 0), (0, 0, 0)),),
    symminformation=msgop(gray[156])[:6],
    basisFunctions=(("dz2", "dxy", "dx2-y2"),),
    InitialBondShells=3,
    GenerateSymmetryGroup=True,
)
second_hamiltonian = hamiltonian_object(1) + hamiltonian_object(2) + hamiltonian_object(3)
# 复用保存的 21 个参数，不调用 fittingTB# Reuse the 21 saved parameters without calling fittingTB
saved_parameters = {'e1': -0.32806081164907486,

全能区与低能窗口Full-energy and low-energy views

# 全能区：TB 与参考带叠加显示，纵轴 -1.5 到 3 eV# Full-energy overlay of TB and reference bands, from -1.5 to 3 eV
full = compareBand(
    fitting_path, 30, second_hamiltonian,
    saved_parameters, vasp_bands, plotRange=(-1.5, 3),
)
# 相同参数的低能窗口；显示范围不裁剪数值数据# Low-energy view with the same parameters; display limits do not truncate numerical data
low = compareBand(
    fitting_path, 30, second_hamiltonian,
    saved_parameters, vasp_bands, plotRange=(-0.5, 0.5),
)
print(full.model.boundary_labels)
print(len(full.model.eigenvalues), len(full.reference_bands))
print(full.model.eigenvalues[0], full.reference_bands[0])
print(low.plot_range)
print(low.model.eigenvalues[60], low.reference_bands[59])
# 保存 compareBand 生成的两张图；交互显示可用 full.show() 或 low.show()# Save both compareBand figures; use full.show() or low.show() for interactive display
full.savefig("compareband-full.svg")
low.savefig("compareband-low.svg")
