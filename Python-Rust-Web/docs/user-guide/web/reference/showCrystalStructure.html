showCrystalStructure

绘制晶胞、原子和磁矩箭头，并保留相应的结构数据。

Draw cell edges, atoms, and magnetic-moment arrows while retaining the corresponding structure data.

01

Examples

四种磁结构Four magnetic structures

02

先运行公共准备代码，然后可分别运行下面四个例子。灰线为晶胞边，球的颜色区分 Wyckoff 轨道；箭头显示磁矩方向，绘制长度由 MomentScale 控制。

Run the shared setup, then run any of the four examples below. Grey lines are cell edges; sphere colours distinguish Wyckoff orbits. Arrows show moment directions, with drawn lengths controlled by MomentScale.

# 四个模型共用 P4 群、同一晶格和绘图范围# The four models share P4 symmetry, a lattice, and a display range
from fractions import Fraction
from magnetictb import bnsdict, init, msgop, showCrystalStructure, symbol

a, c = symbol("a"), symbol("c")
operations = msgop(bnsdict[(75, 1)])

def install(seeds):
    # 每次调用都重新安装给定磁结构# Install the supplied magnetic structure on every call
    init(
        lattice=((a, 0, 0), (0, a, 0), (0, 0, c)),
        lattpar=(("a", 1), ("c", 2)),
        wyckoffposition=seeds,
        symminformation=operations,
        basisFunctions=tuple(("s",) for _ in seeds),
        InitialBondShells=1,
    )

def records():
    # 返回四个平移晶胞的数据，并打印原胞中的记录# Return four translated cells and print the records in the first cell
    result = showCrystalStructure(CellRange=((0, 1), (0, 1), (0, 0)), ImageSize=400)
    print(result.atom_count, result.magnetic_atom_count)
    for atom in result.atom_records:
        if atom.cell_translation == (0, 0, 0):
            print(atom.orbit_index, atom.equivalent_index,
                  tuple(str(v) for v in atom.fractional_position),
                  tuple(round(v, 6) for v in atom.cartesian_moment))
    return result

铁磁Ferromagnetic

# 初始化铁磁模型并读取绘图数据# Initialize the ferromagnetic model and read its plot data
install((((0, 0, 0), (0, 0, 1)),
         ((Fraction(1, 2), Fraction(1, 2), Fraction(1, 2)), (0, 0, 1))))
crystal = records()
# 保存本函数生成的图；交互显示可用 .show()# Save the function-generated figure; use .show() for interactive display
crystal.savefig("crystal-magnetism-1.svg")
