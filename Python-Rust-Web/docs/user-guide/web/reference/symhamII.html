symhamII

把 Rust 生成的 stable convention-I 符号 Hamiltonian 改写为 convention-II Wannier-center 相位。

Rewrite a Rust-generated stable convention-I symbolic Hamiltonian using convention-II Wannier-center phases.

01

symhamII(ham, *, wcc=None) → list[list[HamiltonianExpression]]

参数Parameter默认值Default作用Purpose
ham—Rust Hamiltonian 对象，或由 symham 返回的非空方形 HamiltonianExpression 矩阵。Rust Hamiltonian object or a nonempty square HamiltonianExpression matrix returned by symham.
wccNoneNone 使用当前模型每个 Hamiltonian 行对应的分数轨道中心；也可显式提供每行一个三分量分数中心。None uses the current model's fractional orbital center for every Hamiltonian row; otherwise supply one three-component fractional center per row.
Python 普通二维矩阵是嵌套 list，因此 symham(1) + symham(2) 会拼接行而不是逐元相加。组合多个键层必须先用 hamiltonian_object(1) + hamiltonian_object(2)。A Python ordinary matrix is a nested list, so symham(1) + symham(2) concatenates rows instead of adding entries. Combine shells with hamiltonian_object(1) + hamiltonian_object(2).

# 转换并检查 Hamiltonian 的 Bloch 相位规范# Convert and inspect the Bloch-phase gauge of a Hamiltonian
from fractions import Fraction
from magnetictb import (
    gray, hamiltonian_object, init, msgop, sqrt,
    symbol, symham, symhamII,
)

a, c = symbol("a"), symbol("c")
operations = msgop(gray[191])
init(
    lattice=((a, 0, 0), (-a/2, sqrt(3)*a/2, 0), (0, 0, c)),
    lattpar=((a, 1), (c, 3)),
    wyckoffposition=(((Fraction(1, 3), Fraction(2, 3), 0), (0, 0, 0)),),
    symminformation=operations,
    basis_functions=(("pz",),),
    initial_bond_shells=3,
)
symham(1); symham(2); symham(3)
combined = (
    hamiltonian_object(1)
    + hamiltonian_object(2)
    + hamiltonian_object(3)
)
matrix_ii = symhamII(combined)
print([[str(entry) for entry in row] for row in matrix_ii])
