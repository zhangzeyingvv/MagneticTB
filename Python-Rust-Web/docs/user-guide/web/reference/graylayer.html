Reference Page

graylayer[n]

按层群编号 1–80 返回灰磁层群的三整数数据库标识；用 mlgop 读取完整操作。

Return the three-integer database selector of gray magnetic layer group 1–80; use mlgop for its complete operations.

01

graylayer[n] → tuple[int, int, int]

参数Parameter默认值Default作用Purpose
n必填required1–80 的层群编号。A layer-group number from 1 through 80.

graylayer[25] 返回 (25, 2, 144)；下面把它直接传给 mlgop。

graylayer[25] returns (25, 2, 144); the example below passes it directly to mlgop.

第 25 号灰磁层群的全部操作All operations of gray magnetic layer group 25

# 查询灰磁层群及其有序操作# Look up a gray magnetic layer group and its ordered operations
from magnetictb import graylayer, mlgop

print(mlgop(graylayer[25]))
