symham

求指定键层对 Bloch Hamiltonian 的完整对称性允许贡献。

Construct the complete symmetry-allowed contribution of one bond shell to the Bloch Hamiltonian.

01

symham(shell, *, hermitian=True, cartesian_coordinates=False, validation_level="Basic", kernel_method="Iterative", **stable_options) → list[list[HamiltonianExpression]]

参数Parameter默认值Default作用Purpose
shell必填required1-based 正整数，指定一个已经由 init 或 initfromrep 准备的物理键层。一次调用只返回这一层。A 1-based positive integer selecting one physical shell already prepared by init or initfromrep. One call returns that shell only.
hermitian
Hermitian		True真正的布尔值。True 对正反向 hopping 施加厄米关系；False 允许两个方向拥有独立参数。A genuine Boolean. True imposes the Hermitian relation between forward and reverse hoppings; False allows independent directional parameters.
cartesian_coordinates
CartesianCoordinates		False真正的布尔值。False 保留分数倒空间变量；True 用原始符号晶格精确改写为 Cartesian 动量变量。A genuine Boolean. False keeps fractional-reciprocal variables; True uses the original symbolic lattice to rewrite the result exactly in Cartesian momentum.
validation_level
ValidationLevel		"Basic""None" 不执行求解后的残差认证；"Basic" 精确检查约束残差；"Full" 还检查基底独立性与秩—零度关系。"None" skips post-solve residual certification; "Basic" checks the exact constraint residual; "Full" also checks basis independence and the rank-nullity relation.
kernel_method
KernelMethod		"Iterative""Iterative" / "Stacked" / "Cyclotomic"。三者都使用 Rust 分圆域精确算术且没有数值回退；Iterative 逐块求公共核，Stacked 先堆叠全部约束再求精确零空间，Cyclotomic 使用稳定命名的分圆域精确路径。"Iterative" / "Stacked" / "Cyclotomic". All three use Rust exact cyclotomic arithmetic with no numerical fallback. Iterative intersects constraint blocks successively, Stacked stacks all constraints before the exact null-space solve, and Cyclotomic selects the stable-named exact cyclotomic path.

第 1 层是 onsite，第 2 层是第一个非零距离近邻层，第 3 层是下一距离层。每次只返回一个键层，不累计此前各层，也不会重新运行 init 或扩展键搜索。

Shell 1 is onsite, shell 2 is the first nonzero-distance neighbour shell, and shell 3 is the next distance. Each call returns one shell only; it neither accumulates earlier shells nor reruns init or extends the bond search.

顶层 symham(...) 同时接受表中并列的 snake_case 与稳定风格名称，一次调用请选择其中一种。对象式 PreparedModel.symham(...) 只接受 snake_case。未知关键字抛出 ModelError[UnknownSymhamOption]。Top-level symham(...) accepts either the paired snake-case or stable-style names; use one spelling per call. Object-style PreparedModel.symham(...) accepts snake-case only. Unknown keywords raise ModelError[UnknownSymhamOption].

Basic Examples

Graphene 的完整三个键层All three Graphene shells

02

Input 1 · 完整初始化Complete initialization

symham 不会隐式建立模型。下面先用晶格、Wyckoff 位置、磁空间群和两个 pz 轨道初始化 Graphene 模型。

symham never creates a model implicitly. The following example first initializes a Graphene model from its lattice, Wyckoff position, magnetic space group, and two pz orbitals.

# 定义精确晶格、分数坐标和磁空间群# Define the exact lattice, fractional coordinates, and magnetic space group
from fractions import Fraction

from magnetictb import gray, init, msgop, sqrt, symbol, symham

a = symbol("a")
c = symbol("c")
half = Fraction(1, 2)
third = Fraction(1, 3)

# 安装 Graphene 模型并准备三个键层# Install the Graphene model and prepare three bond shells
init(
    lattice=(
        (a, 0, 0),
        (-a * half, sqrt(3) * a * half, 0),
        (0, 0, c),
    ),
    lattpar=(("a", 1), ("c", 3)),
    wyckoffposition=(((third, 2 * third, 0), (0, 0, 0)),),
    symminformation=msgop(gray[191]),
    basisFunctions=(("pz",),),
    InitialBondShells=3,
    GenerateSymmetryGroup=False,
)
Magnetic space group (BNS): [191, 234]
Lattice: HexagonalP
Primitive Lattice Vactor: [['a', 0, 0], [(-1/2*a), (1/2*(3)^(1/2)*a), 0], [0, 0, 'c']]
Conventional Lattice Vactor: [['a', 0, 0], [(-1/2*a), (1/2*(3)^(1/2)*a), 0], [0, 0, 'c']]
Generators: [('"6z"', 'F'), ('"2x"', 'F'), ('"-1"', 'F'), ('"1"', 'T')]

Rows one and two are the pz orbitals on the two equivalent carbon atoms. Symmetry gives both onsite entries the same parameter e1.

H(\mathbf k)= \begin{pmatrix} e_1+2r_1\!\left(\cos k_x+\cos k_y+\cos(k_x+k_y)\right) &t_1f(\mathbf k)\\ t_1f(\mathbf k)^*& e_1+2r_1\!\left(\cos k_x+\cos k_y+\cos(k_x+k_y)\right) \end{pmatrix},
f(\mathbf k)= e^{-\frac{i}{3}(2k_x+k_y)}+ e^{\frac{i}{3}(k_x-k_y)}+ e^{\frac{i}{3}(k_x+2k_y)}.
普通二维 list 的 + 会拼接行，不是矩阵相加。总 Hamiltonian 必须用高级 Hamiltonian 对象合并，再调用 to_list()。The + operator on ordinary two-dimensional lists concatenates rows; it is not matrix addition. Combine advanced Hamiltonian objects first, then call to_list().

from magnetictb import bnsdict, init, msgop, sqrt, symbol, symham

# 使用只有一个 s 轨道的手性 P3 模型比较厄米选项# Use a chiral P3 model with one s orbital to compare Hermitian options
a = symbol("a")
c = symbol("c")
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 2)),
    wyckoffposition=(((0, 0, 0), (0, 0, 0)),),
    symminformation=msgop(bnsdict[(143, 1)]),
    basisFunctions=(("s",),),
    InitialBondShells=2,
)

p3_hermitian = symham(2)
p3_nonhermitian = symham(2, Hermitian=False)
print([[str(entry) for entry in row] for row in p3_hermitian])
print([[str(entry) for entry in row] for row in p3_nonhermitian])

这是两个完整的 1×1 Hamiltonian。默认矩阵使用 t1,t2；关闭厄米约束后，另一方向的 hopping 得到独立参数 t3,t4。

These are the two complete one-by-one Hamiltonians. The default matrix uses t1,t2; disabling Hermiticity gives the reverse hoppings independent parameters t3,t4.

设正格矢按行组成矩阵 A，键的分数位移为行向量 dfrac。程序先精确计算 dcart=dfracA，再生成 Cartesian Bloch 相位：

Let the direct-lattice vectors be the rows of A and let dfrac be the fractional bond displacement as a row vector. The program first computes dcart=dfracA exactly and then forms the Cartesian Bloch phase:

\mathbf d_{\rm cart}=\mathbf d_{\rm frac}A, \qquad e^{i\mathbf k_{\rm cart}\cdot\mathbf d_{\rm cart}}.

Graphene 最近邻矩阵仍是完整的 2 行 2 列矩阵：

The Graphene nearest-neighbour result remains a complete two-by-two matrix:

H^{(2)}_{\rm cart}(\mathbf k)= \begin{pmatrix}0&t_1\phi(\mathbf k)\\t_1\phi(\mathbf k)^*&0\end{pmatrix},
\phi(\mathbf k)= e^{ia(-k_x/2-\sqrt3k_y/6)}+ e^{ia(k_x/2-\sqrt3k_y/6)}+ e^{ia\sqrt3k_y/3}.
这里采用 row-lattice 约定，已覆盖非正交和剪切晶格；不是只对角晶格才成立的简化式。This uses the row-lattice convention and covers non-orthogonal and sheared lattices; it is not a diagonal-lattice shortcut.

键层越界与非法选项Unprepared shells and invalid options

Input 9 · 未准备的键层Unprepared shell

# 未准备的键层# Unprepared shell
from magnetictb import ModelError

try:
    symham(4)
except ModelError as error:
    print(error.tag)
    print(error.detail)
ShellNotPrepared
shell 4 was not prepared; available shells are 1..3

symham 不会自动寻找新键。需要第 4 层时，必须用 InitialBondShells=4 重新运行完整 init。

symham never searches for new bonds automatically. To use shell 4, rerun the complete init call with InitialBondShells=4.

未准备的键层会抛出 ModelError[ShellNotPrepared]。

An unprepared shell raises ModelError[ShellNotPrepared].
