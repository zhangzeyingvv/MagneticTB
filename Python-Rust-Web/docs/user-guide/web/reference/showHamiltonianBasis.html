showHamiltonianBasis

显示完整 Hamiltonian 基，或解释一个矩阵元的 row/bra 与 column/ket。

Display the complete Hamiltonian basis or identify the row/bra and column/ket of one matrix element.

01

showHamiltonianBasis(row=None, column=None, *, model=None) → TableReport

参数Parameter默认值Default作用Purpose
row, columnNone二者都省略时返回完整有序基；二者都提供时返回指定矩阵元的 row/bra 与 column/ket 基态。不能只提供一个。Omit both for the complete ordered basis, or provide both for the row/bra and column/ket states of one matrix element. Supplying only one is invalid.
modelNoneNone 使用当前会话；也可传入独立 PreparedModel。None uses the current session; a detached PreparedModel may also be supplied.
H_{ij}=\langle i|\hat H|j\rangle=\langle\text{row/bra}|\hat H|\text{column/ket}\rangle.

row 和 column 都是用户显示的 1-based Hamiltonian 索引。

row and column are both 1-based displayed Hamiltonian indices.

Basic Example · input 1

Graphene 完整基Complete Graphene basis

02

先运行 init 页的 Graphene 完整初始化，再查询：

First run the complete Graphene initialization on the init page, then query:

# 读取并检查 Hamiltonian 线性空间基# Read and inspect the Hamiltonian linear-space basis
from magnetictb import showHamiltonianBasis

report = showHamiltonianBasis()
rows = report.to_dict()["rows"]
print(report.title)
for row in rows:
    print(row["HamiltonianIndex"], row["SiteIndex"],
          row["WyckoffOrbitIndex"], row["EquivalentAtomIndex"],
          row["FractionalPosition"], row["BasisFunctionInput"])
Hamiltonian dimension = 2; representation mode = DirectProduct
1 1 1 1 ['1/3', '2/3', '0'] pz
2 2 1 2 ['2/3', '1/3', '0'] pz

两个 pz 态依次构成 symham 返回矩阵的第 1、2 行和列。

The two pz states are rows and columns 1 and 2 of the matrix returned by symham.

Basic Example · input 2

解释 H[1,2]Interpret H[1,2]

03
# 读取并检查 Hamiltonian 线性空间基# Read and inspect the Hamiltonian linear-space basis
element_basis = showHamiltonianBasis(1, 2)
rows = element_basis.to_dict()["rows"]
print(element_basis.title)
for row in rows:
    print(row["Role"], row["HamiltonianIndex"],
          row["SiteIndex"], row["FractionalPosition"],
          row["BasisFunctionInput"])
H[1,2] = <row|H|column>
Row (bra)    1 1 ['1/3', '2/3', '0'] pz
Column (ket) 2 2 ['2/3', '1/3', '0'] pz

因此 Graphene 最近邻矩阵的右上元是从 column/ket 的第二个碳 pz 态到 row/bra 的第一个碳 pz 态的 hopping 和。

Thus the upper-right nearest-neighbour entry is the hopping sum from the second-carbon pz column/ket to the first-carbon pz row/bra.

方向约定不能从矩阵位置猜：请始终使用 row/bra、column/ket 以及 showbonds 的 source/target 记录共同核对。Do not infer direction from matrix position alone; check row/bra, column/ket, and the source/target records from showbonds together.
