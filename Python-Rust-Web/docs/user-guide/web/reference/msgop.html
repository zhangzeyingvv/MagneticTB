msgopReference Page

Reference Page

msgop(group)

读取一个磁空间群的完整、有序对称操作。

Read the complete ordered symmetry operations of a magnetic space group.

01

msgop(group) → list[list]

参数Parameter默认值Default作用Purpose
group必填required磁空间群 selector 或 stable 数据映射返回的 MSGOP 序号；函数返回对应群的完整有序操作表。A magnetic-space-group selector or MSGOP index returned by a stable data mapping; the function returns the complete ordered operation table.

group 可以写成 gray[n]、typeI[(n,m)]、typeIII[(n,m)]、typeIV[(n,m)]，也可以使用 bnsdict、ogdict、ognumdict 或高级 MSG(...) 选择器。

group may be selected with gray[n], typeI[(n,m)], typeIII[(n,m)], typeIV[(n,m)], the bnsdict, ogdict, or ognumdict mappings, or the advanced MSG(...) selector.

每条操作的结构Operation record

[label, rotation, translation, "F" or "T"]

rotation 是 3 行 3 列点操作矩阵，translation 是分数坐标平移。末项 "F" 表示幺正操作，"T" 表示反幺正操作。

rotation is a three-by-three point-operation matrix and translation is a fractional translation. The final flag is "F" for unitary and "T" for antiunitary operations.

Basic Examples

第 191 号灰磁空间群Gray magnetic space group 191

02

Input 1

读取完整列表后可查看显示编号为 1、2、25 的记录。Python 容器从 0 开始，所以对应下标是 0、1、24。

After reading the full list, inspect display records 1, 2, and 25. Python containers are zero-based, so their indices are 0, 1, and 24.

# 读取磁空间群的完整有序操作# Read the complete ordered operations of a magnetic space group
from magnetictb import gray, msgop

operations_191 = msgop(gray[191])
print([operations_191[index] for index in (0, 1, 24)])

前四行是当前 msgop 的真实控制台摘要。随后第一条是单位操作，第二条是六重旋转，第二十五条具有相同空间作用但带时间反演。完整列表可以直接传给 init(..., symminformation=operations_191)。

The first four lines are the current msgop console summary. The first returned record is the identity, the second is a sixfold rotation, and the twenty-fifth has the same spatial action combined with time reversal. The complete list can be passed directly to init(..., symminformation=operations_191).

Properties & Relations

群选择器与表示顺序Group selectors and representation order

03
  • gray[191] 与对应的 bnsdict[(191,234)] 解析到同一磁空间群，因此 msgop 返回完全相同的有序列表。gray[191] and its corresponding bnsdict[(191,234)] selector resolve to the same magnetic space group and therefore return the same ordered list.
  • 列表顺序同时规定 initfromrep 中显式表示矩阵的顺序；程序不会重新排列用户矩阵。The list order also fixes the explicit representation-matrix order used by initfromrep; user matrices are not reordered.
  • msgop 不依赖当前模型会话，可以在 init 之前独立调用。msgop is independent of the current model session and may be called before init.
