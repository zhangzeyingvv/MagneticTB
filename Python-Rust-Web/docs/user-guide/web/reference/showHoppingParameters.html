showHoppingParameters

把 symham 中的独立参数追溯到 Rust 求解得到的实空间 hopping。

Trace independent symham parameters back to Rust-solved real-space hoppings.

01

showHoppingParameters(shell, parameter=None, *, model=None, hermitian=True, kernel_method="Iterative", validation_level="Basic") → TableReport

参数Parameter默认值Default作用Purpose
shell—要检查的 1-based 已准备键层。Prepared 1-based shell to inspect.
parameterNoneNone 为每个参数显示一个 representative source；指定名称则显示该参数的全部实空间出现位置。None shows one representative source per parameter; a name shows every real-space occurrence of that parameter.
modelNoneNone 使用当前会话；也可传入独立 PreparedModel。None uses the current session; a detached PreparedModel may also be supplied.
hermitianTrue是否按 Hermitian 模式构造参数空间。Whether the parameter space is constructed in Hermitian mode.
kernel_method"Iterative""Iterative"、"Stacked" 或 "Cyclotomic"；失败时不自动换方法。"Iterative", "Stacked", or "Cyclotomic"; failure never switches methods automatically.
validation_level"Basic""None"、"Basic" 或 "Full"。"None", "Basic", or "Full".
方向约定固定为 row = bra/destination，column = ket/source。CellTranslation 是 column/source 所在晶胞相对 row/destination 原胞的整数平移。The direction convention is row = bra/destination and column = ket/source. CellTranslation is the integer cell of the column/source relative to the row/destination home cell.

Basic Example · input 1

Graphene 最近邻参数 t1 的代表键Representative bond for Graphene t1

02
# 读取并检查 hopping 参数的实空间位置# Read and inspect the real-space locations of hopping parameters
from fractions import Fraction
from magnetictb import gray, init, msgop, showHoppingParameters
from magnetictb import sqrt, symbol, symham

a, c = symbol("a"), symbol("c")
init(
    lattice=((a, 0, 0), (-a / 2, sqrt(3) * a / 2, 0), (0, 0, c)),
    lattpar=(("a", 1), ("c", 3)),
    wyckoffposition=(((Fraction(1, 3), Fraction(2, 3), 0), (0, 0, 0)),),
    symminformation=msgop(gray[191]),
    basisFunctions=(("pz",),),
)
nearest = symham(2)
report = showHoppingParameters(2)
print(report.title)
for row in report.to_dict()["rows"]:
    print(row["Parameter"], row["ConstraintOrbitIndex"],
          row["BondIndex"], row["ColumnSiteIndex"],
          row["RowSiteIndex"], row["CellTranslation"],
          row["Coefficient"], row["Representative"])
Magnetic space group (BNS): [191, 234]
Lattice: HexagonalP
Primitive Lattice Vactor: [['a', 0, 0], [(-1/2*a), (1/2*(3)^(1/2)*a), 0], [0, 0, 'c']]
Conventional Lattice Vactor: [['a', 0, 0], [(-1/2*a), (1/2*(3)^(1/2)*a), 0], [0, 0, 'c']]
Generators: [('"6z"', 'F'), ('"2x"', 'F'), ('"-1"', 'F'), ('"1"', 'T')]
params: ['t1']
Independent parameter sources for shell 2 (representative hoppings)
t1 1 1 2 1 [-1, 0, 0] 1 True

代表键从 column/ket 的 site 2、晶胞 (−1,0,0) 跳到 row/bra 的原胞 site 1；系数为精确 1。

The representative hopping goes from column/ket site 2 in cell (−1,0,0) to row/bra site 1 in the home cell, with exact coefficient 1.

Applications · input 2

t1 在整层中的 6 个出现位置All six occurrences of t1

# 读取并检查 hopping 参数的实空间位置# Read and inspect the real-space locations of hopping parameters
occurrences = showHoppingParameters(2, "t1").to_dict()["rows"]
for row in occurrences:
    print(row["BondIndex"], row["ColumnSiteIndex"],
          row["RowSiteIndex"], row["CellTranslation"],
          row["Coefficient"], row["Representative"])
1 2 1 [-1, 0, 0] 1 True
2 2 1 [0, 0, 0]  1 False
3 2 1 [0, 1, 0]  1 False
4 1 2 [0, -1, 0] 1 False

前三行产生 symham(2) 的右上矩阵元，后三行是其反向 hopping 并产生左下矩阵元。

The first three rows generate the upper-right entry of symham(2); the last three are reverse hoppings generating the lower-left entry.

Options · inputs 3–5

求解选项与报告必须一致The report must use the same solve options

04

输入 3 · 非厄米Input 3 · non-Hermitian

symham(2, Hermitian=False)
row = showHoppingParameters(2, hermitian=False).to_dict()["rows"][0]
print(row["Parameter"], row["BondIndex"], row["CellTranslation"])

输入 5 · FullInput 5 · Full

# 读取并检查 hopping 参数的实空间位置# Read and inspect the real-space locations of hopping parameters

params: ['t1']
t1 1 [-1, 0, 0]

三个例子都得到同一个代表键，但报告调用仍显式传入与 Hamiltonian 求解相同的选项，避免把不同求解模式的结果混在一起解释。

All three examples yield the same representative bond, but the report explicitly repeats the Hamiltonian solve options so results from different modes are never mixed.
