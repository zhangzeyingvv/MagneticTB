getGenerator

从完整有限群中寻找一组较小的生成元。调用者必须给出单位元和乘法规则；函数不会从群元写法猜乘法。

Find a smaller generating set of a complete finite group. The caller supplies the identity and multiplication law; the function does not infer multiplication from element notation.

01

getGenerator(elements, identity_element, multiply, *, SameTest=None) → list

参数Parameter默认值Default作用Purpose
elements—完整有限群的有序元素序列。Ordered sequence containing the complete finite group.
identity_element—群的单位元。Identity element of the group.
multiply—接受两个群元并返回乘积的可调用对象。Callable accepting two elements and returning their product.
SameTestNone可选的二元相等谓词；省略时使用普通相等关系。Optional binary equality predicate; omission uses ordinary equality.

Basic Example · input 1

加法循环群 C₄Additive cyclic group C₄

02
# 求取并检查有限群生成元# Find and inspect finite-group generators
from magnetictb import getGenerator

print(getGenerator(
    list(range(4)),
    0,
    lambda left, right: (left + right) % 4,
))
[1]

元素 1 的重复加法生成 0,1,2,3，因此返回单元素生成集。

Repeated addition of element 1 generates 0,1,2,3, so a one-element generating set is returned.

Options · input 2

SameTest

03
# 求取并检查有限群生成元# Find and inspect finite-group generators
print(getGenerator(
    list(range(4)),
    0,
    lambda left, right: (left + right) % 4,
    SameTest=lambda left, right: left == right,
))
[1]

SameTest 是对任意元素对返回 bool 的二元谓词；这里显式相等判据不改变结果。

SameTest is a binary predicate returning bool for every element pair; the explicit equality predicate does not change this result.
