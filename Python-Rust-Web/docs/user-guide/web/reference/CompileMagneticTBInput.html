CompileMagneticTBInput(input)

编译一个输入映射并返回不可变 PreparedModel，但不安装当前会话。

Compile an input mapping into an immutable PreparedModel without installing a current session.

01

CompileMagneticTBInput(input) → PreparedModel

参数Parameter默认值Default作用Purpose
input必填required包含稳定编译字段的映射；返回独立的只读模型，不安装当前会话。A mapping containing the stable compiler fields; the result is a detached read-only model and does not install a session.

返回对象支持 compiled["ModelSpecification", "Lattice"] 等结构化键，也保留类型化属性。普通建模仍优先使用 init。

The returned object supports structured keys such as compiled["ModelSpecification", "Lattice"] as well as typed properties. Prefer init for ordinary modeling.

Basic Example · input 1

单 s 轨道立方模型One-s-orbital cubic model

02
# 编译并检查规范化的模型输入# Compile and inspect normalized model input
from magnetictb import CompileMagneticTBInput

identity = ((1, 0, 0), (0, 1, 0), (0, 0, 1))
compiler_input = {
    "Lattice": identity,
    "LatticeParameters": (),
    "WyckoffPosition": (((0, 0, 0), (0, 0, 0)),),
    "SymmetryInformation": (("E", identity, (0, 0, 0), "F"),),
    "BasisFunctions": (("s",),),
    "Debug": False,
    "InitialBondShells": 2,
    "GenerateSymmetryGroup": False,
    "RepresentationMode": "DirectProduct",
    "SiteLocalData": "Automatic",
}
compiled = CompileMagneticTBInput(compiler_input)

lattice = compiled["ModelSpecification", "Lattice"]
print("Lattice", [[str(value) for value in row] for row in lattice.rows])
print("SiteOrbits", [[tuple(str(x) for x in item.fractional_position)
                      for item in compiled.orbital_table]])
print("RepresentationMatrices", [
    [[str(value) for value in row] for row in matrix.rows]
    for matrix in compiled["FullRepresentation", "RepresentationMatrices"]
])
print("FirstBondShell", [
    (bond.shell, bond.bond_id, bond.source_site,
     bond.target_site, bond.translation, str(bond.squared_distance))
    for bond in compiled["ModelSpecification", "BondClasses"][0]
])
Lattice [['1', '0', '0'], ['0', '1', '0'], ['0', '0', '1']]
SiteOrbits [[('0', '0', '0')]]
RepresentationMatrices [[['1']]]
FirstBondShell [(1, 1, 1, 1, (0, 0, 0), '0')]

这里把不可变精确对象转换为短字符串以便阅读；模型内部仍保留完整精确对象。

Exact immutable objects are converted to short strings for readability; the compiled model retains the full exact objects.
