typeI[(n, m)]

返回 BNS 编号为 n.m 的 I 型磁空间群 stable MSGOP 序号；该只读映射含 230 个键。

Return the stable MSGOP index of the type-I magnetic space group with BNS number n.m; this read-only mapping contains 230 keys.
